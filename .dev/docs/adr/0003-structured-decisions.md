# Структурированные проверенные результаты до внешнего действия

Предлагается использовать LLM для извлечения/поиска/объяснения, а критичные допуски и экономику проверять кодом по утверждённым правилам. Альтернатива - свободный агент, который одновременно анализирует, считает и отправляет результат. Она не обеспечивает требуемую проверяемость производственного вывода.

Неопределённость сохраняется явно. Одобрение связано с конкретной редакцией; внешний эффект проходит проверку полномочий и актуальности. Цена компромисса - часть потока уходит человеку, особенно пока справочники и правила неполны.

Ручная отправка пресейла уже описана КП; предложенная техническая реализация требует R10/R22. См. [контракты](../architecture/06-contracts.md).
