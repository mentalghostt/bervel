# ADR-0005: фоновые процессы на Python и PostgreSQL

Дата: 22 октября 2026. Статус: принято владельцем разработки для текущей реализации.

Владелец выбрал самописные Python-сценарии вместо n8n и отдельно подтвердил сохранение фонового запуска, удаление n8n/неиспользуемого Redis, сохранность данных и регрессионные проверки. Это решение заменяет выбор n8n в [ADR-0002](0002-durable-orchestration.md). Исторические испытания остаются свидетельствами прежней реализации.

Используются существующий Python-пакет, отдельный исполнитель и PostgreSQL. Задание, источник, результат и попытки сохраняются в БД. Блокировка на время обработки не позволяет двум исполнителям одновременно выполнять одно задание; транзакционная публикация и проверка активной попытки защищают результат. После аварии требуется явное восстановление. Redis больше не используется и исключён из запуска.

Новые библиотеки, универсальный движок сценариев, автоматические внешние повторы и Temporal не добавляются. Готовые правила CSV и прямой путь сайта сохраняются. Старые данные выведенных сервисов сохраняются архивно, но не являются зависимостью приложения.

Последствия: визуального редактора цепочек больше нет; сценарии меняются в Python-коде и проходят проверки. Длительные ожидания сотрудника, сложные графы и промышленная отказоустойчивость не заявляются готовыми. При появлении таких требований решение оценивается заново по конкретному сценарию.
