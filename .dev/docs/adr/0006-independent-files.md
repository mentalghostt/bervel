# Каждый файл — отдельный неизменяемый оригинал

28 октября 2026 владелец разработки выбрал один постоянный ID для одного неизменяемого файла вместо истории его редакций. Каждая загрузка и сохранение изменённого документа создают отдельный файл; повтор команды с прежним ключом возвращает прежний результат. Исходный документ сохраняется до явного удаления. Так ссылка на источник всегда определяет конкретное содержимое без выбора текущего варианта.

Это заменяет только файловые редакции из [ADR-0004](0004-hybrid-standardized-storage.md). Гибридное хранение, происхождение, доступ, схемы результатов и предметные модели остаются. Собственные редакции наборов данных и обращений, версии схем и алгоритмов не являются редакциями файлов. Таблица файловых редакций и операции истории/замены удаляются; однократная миграция сохраняет структурированные связи и готовые векторы без вызова модели. Исторические тексты и байты сохранённых документов не переписываются.

Контракты, преобразование данных и статус установки: [файлы без редакций](../architecture/25-independent-files.md). Разрешённое отдельным указанием уничтожение 28 скрытых файлов относится к рабочему хранилищу; оно не означает уничтожения прежних независимых резервных копий или исходных папок пользователя.
