# Общие прикладные возможности

Файлы, извлечение, поиск и модельный транспорт доступны через ядро. `company_settings` владеет общими каталогом, складом, себестоимостью, мощностями и ресурсами. Радар и пресейл получают immutable-снимок, не копируя таблицы или правила друг друга.

Неизменяемый оригинал → чтение с локаторами → фрагменты/индекс → поиск кандидатов → чтение источника. Подготовку выполняет knowledge-worker. Semantic top-k не доказывает полный состав. Непрочитанный участок и неизвестные сведения помечаются явно. Смена embedding-модели требует совместимого пространства или отдельно спланированной переиндексации.

Файл имеет один ID; новая загрузка/правка создаёт новый оригинал. Права и происхождение сохраняются в ссылках. Полное удаление очищает производные данные, но не переписывает исторический текст отчёта. [Файловый контракт](25-independent-files.md), [знания](21-shared-knowledge.md).

Модель предлагает кандидатов с доказательствами. Нельзя выводить размеры, стандарт, количество, единицы или возможность производства только из сходства текста. Код проверяет ID/цитаты/числа и считает деньги через Decimal. Внутри расчёта остаток не расходуется дважды; разные тендеры сами по себе не резервируют склад.

Складское покрытие, возможность изготовления, экономика и рекомендация — разные показатели. Неизвестное остаётся неизвестным, известный ноль — нулём. Анализ не означает закупку, резерв, отправку КП, подпись или управление производством.
