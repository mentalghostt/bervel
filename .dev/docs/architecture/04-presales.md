# Пресейл-конвейер

Модуль `modules/presales` установлен 10.11.2026, экран `#/presales`. [Спецификация](../planning/2026-11-10-presales-pipeline-spec.md), [инструкция менеджера](../operations/presales-pipeline.md).

Один комплект файлов создаёт одно обращение и первую редакцию. Редакция фиксирует точные ID оригиналов, настройки пресейла и снимок предприятия. Отдельный worker извлекает позиции, сопоставляет свои товары, распределяет склад, проверяет изготовление и формирует предложение. Изменение настроек не переписывает готовую историю; повторный анализ создаёт новую редакцию.

Статусы: полное складское покрытие, частичное покрытие/изготовление, подтверждённое отсутствие собственного изготовления, спецзаказ. Неизвестное хранится отдельно; недостаток данных не доказывает «Не производим». Покупка у сторонних поставщиков исключена. Цена выводится из `unit_cost` и согласованных правил; неизвестные единицы/себестоимость не превращаются в подтверждённые величины.

Каталог/склад/производство общие с радаром и принадлежат `company_settings`. Собственные настройки, обращения, редакции, строки и очередь принадлежат пресейлу. Экспорты регистрируются через ArtifactService. Stop/Resume сохраняет frozen-входы и завершённые вызовы.

С 11.11.2026 несколько позиций без точного исполнения проверяют спецзаказ общими порциями каталога: факты товара передаются один раз, допустимые SKU и ответ валидируются отдельно для каждой строки. Одновременно выполняются максимум три порции; выбор результата сохраняет порядок порций. Полный prompt ограничивается 48 КиБ, крупный одиночный кандидат не отбрасывается. Завершённые ответы прежних малых порций повторно используются. Durable cache синхронизируется между потоками; heartbeat и чтение интерфейса не загружают его целиком. Глобальный сбой останавливает постановку новых обращений, уже начатые получают сохранённый исход. Склад и мощности распределяются после проверки в прежнем детерминированном порядке.

Полный результат сохраняется один раз в stage:analysis; диагностические calculate/ai_review содержат сводки. Дубли actual_fields удаляются после модельных проверок только при точном совпадении с сохранёнными candidate.fields, поэтому оплаченные запросы и все уникальные факты сохраняются. Каждый ответ получает validated только от собственного валидатора. Resume повторяет явно отклонённый ответ с validation_error, сохраняя ещё не проверенные complete-ответы. Отрицательный совет нормализуется без SKU и доказательств положительного предложения; сырой оплаченный ответ остаётся в cache, положительные рекомендации требуют прежнего точного подтверждения.

Экспорт — проект предложения для менеджера. Автоматическая отправка, запись в CRM/ERP/1 С, резерв и обязательство производства не подразумеваются; клиентские каналы/полномочия уточняются R20–R22.

[Первоначальный выпуск](../quality/2026-11-10-presales-pipeline.md), [оптимизация 11 ноября](../quality/2026-11-11-presales-optimization.md). Настройки открываются попапом внутри конвейера. Интерфейс скрывает технические редакции, SHA, источники в строках и суммы строк; история, оригиналы, расчёты и общий итог предложения сохраняются.
