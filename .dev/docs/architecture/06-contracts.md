# Контракты компонентов

HTTP принадлежит `core/api` или модулю; операции принимают типизированные входы, проверяют права/область и вызывают явно переданные адаптеры. Публичные операции экспортируются через `__init__.py`; чужие private-методы/таблицы не являются API.

| Область | Действующий интерфейс |
|---|---|
| Файлы | `/api/v0.1/artifacts`: создание, список, content, preview, knowledge и удаление; [точные пути](25-independent-files.md) |
| Ассистент | `/api/v0.1/chat`: диалоги, сообщения, очередь; [поведение](26-assistant-data-and-native-web.md) |
| Проверка | `/api/v0.1/inspection`: отдельные native-диалоги; [контракт](32-inspection-engineer.md) |
| Предприятие | `/api/v0.1/settings/company` |
| Радар ИИ | `/api/v0.1/ai-tender-radar` и `/profiles`; [контракт](03-tender-radar.md) |
| Пресейл | `/api/v0.1/presales`: настройки, обращения, редакции, строки, Stop/Resume; [спецификация](../planning/2026-11-10-presales-pipeline-spec.md) |

Точная схема — `/openapi.json` текущего приложения. `/modules`, учебные `/datasets`, `/process-runs`, `/demo/document-review` и файловые `/revisions` удалены.

Эффекты имеют ключ повтора и устойчивую квитанцию. Потерянный ответ не разрешает новый ключ с теми же последствиями; несовместимое тело/версия конфликтует. Владение заданием защищает от поздней публикации старого исполнения. GET/открытие UI не запускают источник, модель или запись настроек.

Модельный результат проверяется по структуре/доказательствам/числам. Ошибка остаётся ошибкой, `unknown` обозначает неизвестный исход. Рекомендация не означает выполненную отправку/участие.

Исполняемые схемы поставляются с приложением; документы из `.dev` не runtime-ресурс. [Границы ядра](12-core-v0.1-spec.md), [доступ веб-сервера](../operations/frontend-server-access.md).
