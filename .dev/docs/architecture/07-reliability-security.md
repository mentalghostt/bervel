# Надёжность, доступ и ограничения

Права/область проверяются сервером до чтения оригинала, поиска и команд с эффектом. Браузерный proxy-ключ общий для согласованной области; полноценного входа/разделения по сотрудникам этот режим не добавляет. [Устройство доступа](../operations/frontend-server-access.md).

Документы — недоверенные данные. Текст закупки не является полномочием отправлять сведения, менять цены или запускать произвольное действие. Модельные выводы проходят предметную/числовую проверку; неизвестное и неполнота сохраняются. Preview не исполняет макросы/HTML/PDF-скрипты.

Native «Проверка» — отдельный настоящий CLI с полномочиями по пользовательской задаче, а не песочница прежнего ограниченного инспектора. Правила пользователя о Git/VPN/OSP/размещении остаются обязательными инструкциями; техническое устройство описано в [контракте 32](32-inspection-engineer.md).

Команды используют ключ повтора, квитанции и проверку версии/владения. Потерянный ответ не доказывает неуспех, unknown не повторяется вслепую. Готовые стадии сохраняются, локальная ошибка карточки не подменяет глобальную auth/storage/Stop-ошибку. GET/reload не создаёт эффектов.

Секреты находятся в окружении/приватных хранилищах, не в Git, HTML/JavaScript или журнале. Private repo не заменяет право обработки/передачи клиентских документов. Поиск/модель получают только доступные источники с явным происхождением.

Копия БД, оригиналы и необходимые настройки образуют связанную резервную копию. Старые backuphelpers учебной схемы сняты как невалидные после 0013; готового универсального автоматического workflow сейчас нет. Новая проверенная процедура должна адресовать фактическую схему/volumes и репетировать восстановление в изоляции, не перезапуская рабочие сервисы ради smoke. [Данные Docker](../operations/docker-local.md).

Промышленные SLA/RPO/RTO, сроки хранения, разрешённые поставщики и политика данных требуют ответа владельцев R06/R09/R16–R18. Локальные тесты и репликация не заменяют проверку восстановления. Нельзя считать downgrade схемы безопасным автоматически или применять все migration heads из отложенного кода. [Открытые решения](09-open-decisions.md).
