# Открытые решения и текущая реализация

DEC-01–DEC-12 сохраняют связь с исходными R01–R22. Технические решения разработчика не закрывают клиентские условия поставки/эксплуатации.

| ID | Решение | Что остаётся уточнить | Текущая техническая основа |
|---|---|---|---|
| DEC-01 | Состав поставки | Клиентский объём R01 | Радар ИИ/пресейл реализованы по заданиям владельца, это не подпись заказчика |
| DEC-02 | Фоновые процессы | Эксплуатационная нагрузка R08/R09/R16/R18 | Python/PostgreSQL, n8n/Redis выведены |
| DEC-03 | Источники закупок | Действующий доступ/лицензия/полнота R11 | Явно выбранный Контур API или симулятор; нет скрытого fallback |
| DEC-04 | Каталог/производственные правила | Подтверждённые факты завода R05/R12/R13 | Общие снимки предприятия; unknown при нехватке доказательств |
| DEC-05 | Экономика | Эталонные себестоимость/нормы/единицы R14 | Расчёты по сохранённым входам, без выдуманных величин |
| DEC-06 | Модель/данные | Разрешённые поставщики/политика R17/R18 | Настроенный Codex/embedding-провайдер, источники с доступом |
| DEC-07 | Размещение/надёжность | SLA/RPO/RTO, бюджет, эксплуатация R08/R09/R16/R18 | Локальный Docker, без заявленной промышленной гарантии |
| DEC-08 | Полномочия | Состав внешних действий R10 | Анализ/экспорт не разрешают отправку, резерв, подпись или подачу |
| DEC-09 | Хранение | Политика оригиналов/аудита/копий R06 | Не назначать произвольный срок; подтверждённое удаление отдельно |
| DEC-10 | Пресейл-интеграции | Каналы/CRM/ERP/1 С/отправка R20–R22 | Конвейер локально установлен; внешние интеграции не подразумеваются |
| DEC-11 | Чертежи/дооснащение | Включение и источники R13–R15 | Условные расширения не реализуются автоматически |
| DEC-12 | Пакет участия | Объём/полномочия R19 | Не означает автоматическую подачу или электронную подпись |

Пакет 06.10 дал реальные внешние образцы; он не подтвердил все производственные данные и полномочия. Наличие каталожной позиции, складского остатка, мощности и утверждённой замены — разные факты. [Покрытие запросов](../discovery/customer-package-request-coverage.csv), [первичные источники](../sources/README.md).

Сохраняются принятые принципы [модульного монолита](../adr/0001-modular-core.md), [проверяемых результатов](../adr/0003-structured-decisions.md), [хранения](../adr/0004-hybrid-standardized-storage.md), [Python/PostgreSQL](../adr/0005-python-background-processes.md), [самостоятельных файлов](../adr/0006-independent-files.md).

Для закрытия решения нужны владелец, дата, источник фактического ответа, формулировка, затронутые компоненты и ограничения. Молчание/образец/КП не равны согласию. [Реестр запросов](../discovery/requests.csv).
