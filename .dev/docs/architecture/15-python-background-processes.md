# Фоновые процессы на Python и PostgreSQL

Дата: 22 октября 2026. Владелец выбрал сохранить фоновый запуск через Python/PostgreSQL, удалить n8n и неиспользуемый Redis, сохранить данные и проверить загрузку, просмотр и защиту от дублей.

API сохраняет задание в существующих таблицах PostgreSQL и сразу отвечает. Отдельный процесс `python -m bervel worker` берёт задание и вызывает существующий CSV-обработчик. Прямой путь загрузки с сайта остаётся прежним. Новые библиотеки, внешний движок и отдельный брокер не нужны.

Исполнитель удерживает сессионную блокировку PostgreSQL на время обработки. Другая копия исполнителя пропускает занятое задание. Публикация результата и завершение попытки остаются одной транзакцией, с проверкой номера попытки и точной редакции источника. Ключ команды сохраняет прежнее назначение: повтор той же команды возвращает прежний процесс; изменённое тело под тем же ключом отклоняется.

После аварии незавершённая попытка требует явного восстановления. Сверка проверяет блокировку в PostgreSQL; активную работу повторить нельзя. Если соединение исполнителя утрачено, оператор может создать новую попытку. Старая попытка после этого не имеет права публиковать результат. Автоматические повторы внешних действий и универсальная система длинных сценариев не добавляются.

Сохраняются публичные маршруты запуска, списка, чтения, сверки и восстановления. Служебные HTTP-вызовы прежнего движка и их ключи удаляются: Python-исполнитель работает непосредственно через прикладной слой и репозиторий. Завершённые исторические процессы остаются читаемыми. Сценарии, закреплённые за выведенной из эксплуатации реализацией, автоматически не переисполняются; новый запуск использует новую команду и прежний оригинал.

Удаляются адаптер, настройка и схема n8n, его Compose-профиль, Redis, активные инструкции и инструменты старого стенда. Архивные документы и первичные источники сохраняются как история, с отметкой о замене решения. База приложения и оригиналы сохраняются на прежних volumes. Исторические данные выведенных сервисов сохраняются отдельно и не используются новым запуском.

Проверки: повтор и конфликт команды, конкурентные исполнители, прерывание и восстановление, запрет поздней публикации, атомарный откат, чужая область, несовместимая версия, прежние загрузки и строки, браузерные загрузка/просмотр/повтор после потери ответа. До замены: 95 серверных тестов проходят. Резервная копия: `.dev/local/docker/backups/docker-20261022T091022Z`.
