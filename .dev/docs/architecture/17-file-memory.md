# Общая память загруженных файлов

Обновление28.10.2026: файловый контракт заменён моделью [отдельных неизменяемых файлов](25-independent-files.md), принятой в [ADR-0006](../adr/0006-independent-files.md). Описание редакций файлов ниже сохраняется как история; собственные редакции результатов, обращений и схем этим решением не отменяются. Статус установки указан в новом документе.

Автономный запрос 22 октября 2026: Codex должен находить все загруженные файлы, включая будущие PDF, изображения и неизвестные форматы, с указанием источника. Корень C:/OSPanel/home/bervel.local, core, только чтение Git. Авторизация/MOX/VPN неизменны.

Реестр оригиналов уже принимает любой MIME. Новый вопрос фиксирует актуальные редакции всех оригиналов своей области; старый snapshot одного CSV продолжает читаться. Поиск использует имя/тип и текстовые фрагменты разных файлов в PostgreSQL. Вопросы о последнем CSV сохраняют точный выбор по времени; общий поиск не ограничивается последним. Любые форматы доступны по метаданным; неизвестный/повреждённый/зашифрованный формат не объявляется прочитанным.

DocumentMemory — прикладной поиск, проверка доступа/целостности, выбор и ограничения контекста. DocumentReader — внешний адаптер: CSV parser, UTF-8 text, PDF text через Poppler, OCR изображений/сканов через Tesseract rus+eng. Извлечения кэшируются в additive document_indexes по artifact/revision/version. Метаданные доступны без декодера. Никакого shell исполнения пользовательских строк: subprocess только фиксированные программы/аргументы и созданные временные имена, таймауты/лимиты. Первое чтение может потребовать индексации; новые вопросы используют кэш. Хранилище оригиналов не передаётся CLI целиком.

До 16000 символов извлечений и до 12 фрагментов из разных файлов. Сначала резервируются лучшие фрагменты разных подходящих файлов, затем добавляются дополнительные; большой документ не вытесняет второй явно названный. Источник содержит имя, ID, редакцию, время, unit row/line/page/image/metadata, диапазон, статус, excerpt и truncated. Совпадение по имени имеет приоритет. При неполной выдаче/невозможном чтении модель получает явное ограничение; ей запрещены полные итоги и выдуманные данные. Проверка целостности оригиналов сохраняется даже при кэше. Недоступный оригинал становится metadata_only без его старого текста; отказы доступа не маскируются. Временная ошибка чтения не кэшируется навсегда и не блокирует исправные файлы.

Выбранные PNG/JPEG/WebP можно передавать CLI как local_image через временный файл runner: до двух изображений/5 МиБ суммарно. Передаются только проверенные bytes выбранных источников; image_attached указывает, действительно ли изображение передано модели. Runner не принимает произвольные пути, удаляет временные файлы, не открывает shell. Общий индекс также содержит OCR-текст изображений. PDF ограничен 100 страницами текста, OCR первых 10 пустых страниц, общим сроком около 60 секунд; дальнейшие ограничения видимы. Декодеры ограничены 40 секундами на процесс, 768 МиБ адресного пространства, 30 CPU-секундами и 4 МиБ на выходной файл; родитель читает до 2 МиБ. Поддержка новых парсеров добавляется в DocumentReader без изменения каталога/очереди/диалога.

Во вкладке файлов — отдельная загрузка любого оригинала до 5 МиБ без CSV-извлечения. Старый CSV-поток с предметной обработкой сохраняется. Чат показывает источники разных типов и ссылку получения оригинала через тот же авторизованный API. Секреты только на сервере, никакого прямого файлового доступа Codex к проекту.

Семантические embeddings, отдельная векторная БД, ZIP extraction, исполнение офисных макросов, URL scraping и неограниченное понимание любого бинарного формата не входят в решение. Общий каталог не зависит от формата; возможность прочитать содержимое явно указана.
