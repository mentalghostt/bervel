# BERVEL после удаления учебного CSV

Действующая редакция от 26 октября 2026. Уточняет [карту Python от 23 октября](19-python-layout.md) и заменяет учебный CSV-путь из прежних описаний фоновых процессов.

## Действующие сценарии

- «Файлы»: загрузка произвольного оригинала, список, редакции, скачивание и preview. Это начальный экран, включая старый адрес `#/`.
- Чат: история, устойчивая очередь ответа, источники из закреплённого каталога, чтение документов и генерация.
- Тендерный радар: импорт выгрузки закупок CSV/XLSX, явный выбор редакций документов, первичный отбор, проверенный отчёт и PDF.

`core/csv_memory.py`, `DocumentReader`, `DocumentMemory`, индекс документов версии 4, preview и импорт радара сохраняются. Разбор CSV для подготовки контекста — рабочая возможность. Он не требует учебной публикации dataset.

## Что удалено

Пакет `modules/document_review`, `ExtractionService`, `ProcessService`, репозиторий/модели учебных попыток, регистрация JSON Schema и типы учебных результатов. Удалены `/demo/document-review/*`, `/process-runs*`, `/datasets/*` и учебный `/modules`. Список оригиналов и история больше не выдают учебные datasets; frontend не показывает их таблицы/статусы.

Зависимости `jsonschema[format]` и `referencing` и их неиспользуемые транзитивные пакеты исключены из runtime. Версии оставшихся пакетов сохранены. Стабильная сериализация для command receipts перенесена из бывшего валидатора в `core/infrastructure/commands.py` без изменения формата.

## Исполнение и границы

`app_setup.build_services` соединяет общие оригиналы, документную память, модельный клиент, чат и радар. Worker последовательно вызывает `chat.run_once()`, затем `radar.run_once()`. Их очереди, блокировки, обработка неизвестного исхода и права доступа сохранены. API и worker используют один Python-пакет в разных процессах.

Исторические разрешения в существующих access bindings не переименованы: часть токенов `dataset:*`/`process:*` используется действующим радаром и проверками доступа к документам. Старые имена метаданных не являются признаком работающего учебного сценария.

## Данные и совместимость

Миграции `0001`–`0007`, прежние таблицы и записи сохраняются. Удаление активного сценария не выполняет `DROP`/`DELETE` и не переписывает исторические редакции. SQL-описания исторических таблиц остаются в metadata для совместимости схемы и миграционных проверок. Новых миграций нет.

Изменён публичный контракт списка/истории: поля `dataset` и `datasets` удалены. Клиенты учебных endpoint должны перейти на оригиналы и preview. Существующие контракты чата/радара, источники, оригиналы и скачивание PDF сохранены.

## Проверка

Backend проверяется по установленному wheel и временным схемам выделенной БД `bervel_core_stage31_test`; `conftest.py` запрещает другой database. Регрессии удаления — `.dev/tests/test_retired_csv.py`. Рабочие тесты чтения, индекса, CSV preview, чата, радара, импорта, PDF и доступа сохранены.

Браузерные проверки: `npm run test:frontend` из `.dev`. Вместо учебных upload tests выполняются `frontend-retired-csv.cjs` и живой `frontend-originals-live.cjs` (`npm run test:frontend:live`). SQL-проверка живой загрузки подтверждает оригинал и отсутствие созданного учебного dataset.

Инженерный атлас: `.dev/visualizations/bervel-code-map.html`. Пересборка: `node .dev/scripts/build-code-map.cjs`.
