# Рабочее пространство BERVEL

Страницы определены в `frontend/src/App.tsx`; hash-навигация переключает раздел, данные сохраняются backend.

| Экран | Назначение |
|---|---|
| `#/files` | Загрузка/список/preview/удаление самостоятельных файлов |
| `#/chat` | Диалоги ассистента |
| `#/inspection` | Настоящий native Codex CLI |
| `#/ai-tender-radar` | Профили источников и карточки |
| `#/presales` | Комплекты файлов, редакции, предложение |
| `#/tickets` | Внутренние обращения |
| `#/company-settings` | Общие каталог/склад/производство |
| `#/settings` | Настройки модели/источника/радара |

`#/ai-radar-runs` совместим с AIрадаром; обычный `#/radar` выведен. Исходники `#/presales-settings`/нового попапа не доказывают их установку.

Файл имеет точный ID; новая загрузка/правка создаёт новый оригинал. Удаление подтверждается отдельно и не заменяет исторический источник похожим документом.

Ассистент использует типизированные действия/квитанции; Проверка — отдельный native thread. Внутренние `tickets` и клиентские `presales` — разные сущности. Доставленный ответ не означает успех каждого эффекта.

Радар/пресейл получают общие immutable-снимки предприятия, но имеют отдельные очереди/историю. Анализ не резервирует склад, не отправляет КП и не подаёт заявку.
