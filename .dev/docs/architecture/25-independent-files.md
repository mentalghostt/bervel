# Файлы: один оригинал — один ID

Каждая загрузка или сохранённая правка создаёт отдельный неизменяемый файл. Ссылки адресуют точные байты через `ArtifactRef(artifact_id)`. Совпадение имени/содержимого не превращает загрузки в редакции одного документа. Изменение назначения файла не меняет его байты.

Файловые `artifact_revisions`, `current_revision`, операции revise/history и HTTP `/revisions` отсутствуют. Предметные редакции пресейла/обращений и версии алгоритмов сохраняют собственный смысл.

## HTTP

Все пути имеют префикс `/api/v0.1` и проверяют право/область:

| Операция | Путь |
|---|---|
| Регистрация | `POST /artifacts` → `{artifact_id}` |
| Список | `GET /artifacts?cursor&limit` |
| Метаданные | `GET /artifacts/{id}` |
| Байты | `GET /artifacts/{id}/content` |
| Preview | `GET /artifacts/{id}/preview?cursor&limit` |
| Подготовка для ИИ | `GET /artifacts/{id}/knowledge` |
| Продолжение подготовки | `POST /artifacts/{id}/knowledge/resume`, тело `{}` |
| Назначение | `PUT /artifacts/{id}/usage-role` |
| Полное удаление | `DELETE /artifacts/{id}` →204 после очистки |

Файловые `revision`/`expected_revision` отклоняются 422. Закладка `#/files?artifact_id=UUID` открывает точный файл; старый параметр revision обозначает устаревшую ссылку, а не автоматический выбор похожего оригинала.

## Удаление и повтор

Полное удаление очищает байты и производные документы/векторы файла. Если байты используются другой самостоятельной загрузкой, она сохраняется. Истории чатов/анализов/предложений и квитанции команд не стираются. Минимальная отметка удалённого оригинала не хранит имя/содержимое: свой источник возвращает 410, чужая область 404.

Активная подготовка блокирует удаление 409. Ошибка физической очистки не выдаётся за 204; существующий knowledge-worker продолжает устойчивую очистку. Новая попытка загрузки после потерянного ответа использует тот же ключ команды; completed/failed/unknown не позволяют воскресить удалённый результат.

## История перехода

Миграция 0013 преобразовала именованные технические ссылки файлов/индексов/квитанций; предметное поле revision и свободный пользовательский текст не означают файловый номер. История 0001+ сохраняется и нужна для установки текущей схемы 0029. Учебные datasets не являются действующим контрактом.

[Условия перехода](../planning/2026-10-28-files-without-revisions-design.md), [сохранённый план](../planning/2026-10-28-files-without-revisions-plan.md) и [фактическая проверка](../quality/files-without-revisions-2026-10-28.md) относятся к конкретному переходу. Их ранние статусы/числа не являются свежей инвентаризацией рабочей БД. Отдельные pending-изменения и права на дальнейшее удаление данных из этого исторического перехода не следуют.
