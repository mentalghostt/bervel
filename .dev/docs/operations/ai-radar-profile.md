# Радар ИИ: работа с профилями

Открыть [Радар ИИ](http://127.0.0.1:5173/#/ai-tender-radar). Профиль хранит постоянную подборку выбранного источника. [Контракт под капотом](../architecture/03-tender-radar.md).

1. В «Файлах» загрузить необходимые исходники; в «Настройках предприятия» проверить общий каталог, склад, `unit_cost`, нормы/ресурсы и сохранить снимок. Просмотр не сохраняет новый снимок.
2. Выбрать источник профиля. Для Контур API нужны действующий ключ/доступ и явный выбор; симулятор не является настоящим источником.
3. Открыть обновление и задать явную квоту/правила ручного повторного анализа. Запуск сохраняет входы/ключ команды и начинает source→documents→matching→calculations→rating.
4. Следить за этапом и карточками. Законченный анализ/индивидуальный балл появляются по мере сохранения, без ожидания всей группы.
5. Открыть карточку: проверить документы/доказательства, каталог/склад, изготовление, экономику, неизвестные сведения и замечания. Вопрос относится к этой сохранённой карточке.

Автообновление настраивается отдельно: расписание и его флаг повторного анализа не заменяют ручной выбор. Сохранение расписания не выполняет немедленный платный поиск. По умолчанию обе опции повторного анализаfalse; новая ручная команда не меняет auto-настройку.

Локальный пересчёт метрик использует сохранённые сведения и актуальный снимок предприятия; он не равен новому source-поиску/разбору документов. Открытие/обновление страницы является чтением и не запускает модели.

При ошибке доступны фактическое состояние и разрешённое продолжение. Resume использует сохранённые входы/этапы; не повторяйте команду с новым ключом при потерянном ответе. Stop не откатывает уже выполненные действия. Завершение «с замечаниями» означает, что часть карточек не получила полный валидный результат; завершённая группа не требует Resume только из-за этих предупреждений.

Последний подтверждённый обход дал 377 готовых и 23document-warning. [Адресный ремонт 23](../planning/2026-11-10-radar-document-repair.md) не завершён. Нельзя скрывать предупреждения, объявлять 400 валидных анализов или запускать общий refresh вместо требуемой адресной операции.

Подтверждённое покрытие, возможность изготовления и рекомендация — разные результаты. Анализ не резервирует склад/станки и не разрешает подачу/подпись. Величины без источника не заменяются нулём; сроки подачи/поставки не смешиваются. Ограничения промышленного доступа и реальных данных завода остаются явными.

Установленная основа включает поздний пресейл/схему 0029 и ngrok-frontend. Старые radar-only images/одноразовые установщики не применять. [Docker и данные](docker-local.md), [проверенный итог](../quality/2026-11-10-radar-completion.md).
