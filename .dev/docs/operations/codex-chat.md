# Чат и настройки Codex локально

Файловый контракт28.10.2026 заменяет прежнюю адресацию редакций: [отдельные неизменяемые файлы и статус установки](../architecture/25-independent-files.md). Используются точные ID; загрузка/сохранение правки создают самостоятельный файл. Прежние примеры и результаты ниже сохраняют исторический контекст.

Чат расширен до «Универсального ассистента»: [действующие возможности, голос и обращения](workspace-assistant-radar.md). Описание настроек основного шлюза ниже сохраняется.

Открыть http://127.0.0.1:5173/#/settings. По умолчанию MOX Access. Для прямого API выбрать «API-ключ», указать модель, HTTPS-адрес Responses API (OpenAI: https://api.openai.com/v1), вставить ключ и сохранить. Ключ не возвращается в браузер и не записывается в исходники; он находится в отдельном Docker volume с правами файла 0600. При переключении сохранённый ключ остаётся. Пустое поле при последующем сохранении сохраняет прежний ключ.

«Проверить подключение» доступно для сохранённого профиля с указанным доступом. Проверка отправляет короткий вопрос; успех показывает точный ответ модели. При TLS/auth ошибке приложение показывает безопасную ошибку и не повторяет запрос. Установленный CLI не означает наличие доступа к облачной модели.

Для этого компьютера MOX запускается из корня проекта:

```powershell
.dev/scripts/docker.ps1 -Action start -Mox
```

Флаг -Mox подключает существующие ~/.codex/auth.json и config.toml только для чтения. При необходимости абсолютные пути задаются переменными процесса BERVEL_MOX_AUTH_PATH и BERVEL_MOX_CONFIG_PATH. Скрипт не выполняет login/logout и не копирует auth. Только публичный сертификат из существующего доверенного Windows Root экспортируется в ignored docker/mox/ca.pem и подключается контейнеру для Node/CLI; сертификат и настройки самого MOX не меняются. При смене внешнего auth атомарной заменой пересоздать codex тем же Compose-подключением. Не публиковать эти файлы и не добавлять реальные токены в проект.

У заказчика без MOX:

```powershell
.dev/scripts/docker.ps1 -Action start
```

После запуска выбрать API-ключ во вкладке. Если модельный доступ ещё не настроен, загрузка/просмотр CSV продолжают работать.

Чат: http://127.0.0.1:5173/#/chat. На http://127.0.0.1:5173/#/files есть отдельная форма «Добавить файл в память чата»: принимает любой непустой оригинал до 5 МиБ без запуска CSV-обработчика. Старая вкладка CSV сохраняет прежнюю предметную обработку. Каждый вопрос фиксирует каталог всех актуальных редакций в своей области данных. Можно назвать старый файл, сравнить несколько источников или спросить «Что в самом последнем CSV» — последний CSV выбирается отдельно от более новых загрузок других типов.

Читаются CSV, UTF-8 тексты, текстовые PDF, сканы PDF и текст изображений через OCR rus+eng. Выбранные PNG/JPEG/WebP дополнительно передаются модели для визуального просмотра. Любые другие оригиналы находятся по имени и свойствам; неизвестный, повреждённый или зашифрованный формат имеет явный статус «содержимое не прочитано». Источники показывают точное имя/редакцию, строки/страницы/изображение, реальный отрывок и кнопку скачивания оригинала. Индексы и диалоги сохраняются в PostgreSQL; не требуется перезагружать прежние файлы.

Поиск использует слова и имена, а не семантические embeddings. В одном вопросе до 12 фрагментов и 16000 символов; у разных подходящих файлов резервируется по фрагменту. PDF: до 100 страниц текста, OCR до 10 пустых страниц, общий срок около 60 секунд на PDF; текстовые извлечения ограничены 200000 символами. Изображения для модели: до двух / 5 МиБ суммарно. Неполное извлечение и выбор части фрагментов помечаются явно. Это не доказательство проверки всех строк большого файла. Недоступность одного оригинала не блокирует остальные; его непроверенный текст из кэша не используется.

Блокер TLS устранён 22 октября 2026 внутри контейнера: добавлен доверенный публичный сертификат, сохранено имя localhost через прозрачный loopback TCP bridge. Полная проверка TLS проходит, настоящий Codex ответил OK. Отчёт предыдущей проверки: ../quality/codex-mox-tls-report.md. При расширении памяти MOX/auth/config не менялись. В каталоге оставлены пять новых контрольных файлов memory-*; memory-stock-6318.csv теперь последний CSV. Шесть реальных ответов MOX, OCR/vision, SQL, reload и скачивание подтверждены: ../quality/file-memory-report.md.

Текущая архитектура памяти: ../architecture/17-file-memory.md; исходная интеграция: ../architecture/16-codex-chat.md. Настройки общие для всех посетителей текущего сайта с общим server web key; отдельного входа сотрудников нет.
