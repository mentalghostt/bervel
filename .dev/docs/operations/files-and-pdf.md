# Файлы и системный PDF

Интерфейс ниже частично исторический: актуальная компоновка описана в [рабочем пространстве](workspace-assistant-radar.md). Файловый контракт28.10.2026 подготовлен к основной установке: [один файл — один ID](../architecture/25-independent-files.md); статус установки указан там.

## Удаление файла навсегда

Во вкладке «Файлы» выберите оригинал и подтвердите его полное удаление. Удаляются оригинал, извлечённые фрагменты и поисковые векторы этого файла. Если одинаковые байты используются другой загрузкой, её оригинал остаётся доступен; физическая общая копия исчезает после последнего удаления.

Чаты, цитаты и сохранённые отчёты остаются; скачивание удалённого источника показывает «Файл удалён». Восстановления через интерфейс нет. Минимальная служебная отметка позволяет отличить удалённый источник от неизвестного ID, без сохранения его имени и содержимого.

Если идёт подготовка для ИИ, дождитесь завершения текущей порции и повторите удаление. Если не удалось завершить очистку хранилища, интерфейс сообщает об ошибке; подтверждённую очистку продолжает существующий knowledge-worker. Ошибка одного файла не приостанавливает обработку других файлов.

Контракт после0013: `DELETE /api/v0.1/artifacts/{id}`, право `artifact:write`, собственная область данных, HTTP204 только после очистки; HTTP409 при активной индексации, HTTP410 при чтении удалённого источника. Старый expected_revision отвергается с422. Миграция0010 добавила очередь удаления и независимость исторических импортов радара;0013 переводит файлы и ссылки на один ID. [Исторические проверки полного удаления](../quality/file-deletion-2026-10-27.md).

Обновление 22.10.2026 по запросу владельца. [Проверки и доказательства](../quality/files-pdf-report.md).

## Файлы

Открыть [раздел «Файлы»](http://127.0.0.1:5173/#/files). На широком экране слева список занимает треть доступной ширины, справа просмотр — две трети. На мобильном просмотр располагается под списком. Ограничение `max-w-6xl` убрано из оболочки и всех страниц; поля и ограничение длины отдельных пояснений сохранены.

Нажать название файла. Предварительная обработка не нужна: просмотр читает сохранённый оригинал с проверкой прав, ID, размера и SHA256. Учебный сценарий обработки CSV удалён26.10; просмотр CSV показывает исходные строки файла.

- PNG/JPEG/WebP/GIF/BMP: изображение с сохранением пропорций. Тип проверяется по содержимому, не только по присланному MIME.
- PDF: страницы отображаются PDF.js внутри приложения; кнопки «Предыдущая страница» и «Следующая страница». Браузерный PDF-плагин не требуется. Worker, стандартные шрифты, CMaps/ICC/WASM поставляются локально, CDN и отправки документов стороннему сервису нет. PDF-скрипты/внешние действия не выполняются. Для защищённого или повреждённого PDF показана ошибка и доступен оригинал.
- CSV с любыми колонками: таблица исходных строк, без требования `line,name,quantity,unit`. Сохраняются точные числовые строки и ведущие нули. Разделители запятая/точка с запятой/табуляция, UTF-8/BOM, UTF-16 с BOM, Windows-1251. Дубли заголовков сохраняются; недостающие ячейки дополняются для просмотра, дополнительные получают «Колонка N» и предупреждение. По 100 строк; длинные значения прокручиваются внутри ячейки без потери текста.
- UTF-8 текст и HTML показываются как текст, без выполнения разметки. DOCX/XLSX имеют текстовое представление, а не точную копию исходного оформления.
- Для остальных форматов указано ограничение просмотра; «Скачать оригинал» сохраняет исходный файл.

Предел оригинала 5 МиБ. CSV до 10000 строк и 200 колонок; обрезка числа строк обозначена явно, полные данные доступны в оригинале. Предельная длина CSV-поля задаётся стандартным ограничением Python CSV (128 КиБ); превышение или повреждение формата не выдаётся за успешный просмотр. Для больших текстов показываются первые 200000 символов. DOCX/XLSX сохраняют прежние ограничения архива/извлечения. Canvas PDF ограничен 4 млн пикселей/4096 по высоте; просмотр не является редактором, слоем выделения текста или проверкой электронной подписи.

«Загрузить файл» раскрывает форму, «Обновить список» перечитывает прежние загрузки. Смена выбранного файла отменяет запрос и освобождает blob URL/worker; поздний ответ не заменяет новый выбор. При ошибке загрузки самого PDF-модуля список и скачивание остаются доступны, сообщение предлагает обновить страницу.

## PDF радара

Открыть завершённый результат на [странице радара](http://127.0.0.1:5173/#/radar?run=78ca94fa-6be4-445b-86e2-b06cf5c99804) и нажать «Скачать PDF».

PDF создаётся из уже сохранённого отчёта, без нового запроса к модели и без изменения данных. Включены время анализа, сводка, выбранные файлы с точными ID, все четыре категории, все закупки, риски, следующие действия и доказательства. Готовность к участию от экспорта не меняется.

Шаблон BERVEL версии 1.0 фиксирован в `src/bervel/modules/tender_radar/infrastructure/pdf.py`: A4, поля, палитра приложения, иерархия, колонтитулы и встроенные Noto Sans Regular/Bold. Шрифты и лицензия поставляются с wheel. Модель возвращает содержание, не стили; текст экранируется, только HTTP(S)-ссылки становятся кликабельными. Одинаковый сохранённый запуск даёт одинаковые байты PDF. Изменение шаблона — изменение кода с новой проверкой оформления.

Авторизованный `GET /api/v0.1/radar/runs/{id}/report.pdf` доступен только для завершённого отчёта и с прежними правами/областью/actor запуска. `GET /api/v0.1/artifacts/{id}/preview` возвращает явный DTO просмотра; оригинал читается прежним защищённым `/content`. Просмотр не создаёт dataset и не запускает модель/OCR. Установку и настройки MOX менять не требуется; команды Docker прежние.
