# Файлы: просмотр, оригиналы и удаление

Открыть [«Файлы»](http://127.0.0.1:5173/#/files), загрузить оригинал и выбрать его в списке. Файл имеет один самостоятельный ID; правка/повторная загрузка создаёт новый файл. Просмотр читает проверенный доступный оригинал и не запускает учебный CSV-анализ, модель или OCR.

| Формат | Представление |
|---|---|
| PNG/JPEG/WebP/GIF/BMP | Изображение с сохранением пропорций, тип проверяется по содержимому |
| PDF | Локальный PDF.js и страницы внутри приложения; PDF-скрипты/внешние действия не выполняются |
| CSV | Таблица исходных строк, без обязательной учебной схемы; до 100 строк за страницу |
| DOCX/XLSX | Текстовое представление, а не копия оформления |
| Текст/HTML | Текст без выполнения HTML/команд |
| Прочее/повреждённое | Явное ограничение и доступное скачивание оригинала |

CSV-preview ограничен 10000 строками/200 колонками; ограничение обозначается, полные байты доступны в оригинале. Ведущие нули/числовые строки сохраняются. Длинные тексты preview показывают первые 200000 символов. Ограничения чтения/архивов/OCR и памяти браузера не означают, что исходный документ усечён при хранении.

Прежний общий предел 5 МиБ снят из загрузки/регистрации/download. Конкретные транспорт, декодер и браузер имеют собственные ограничения; неподдерживаемое не выдаётся за полный просмотр. Смена выбора отменяет прежнее чтение и не подставляет поздний ответ.

## Полное удаление

Выбрать файл и подтвердить удаление. Удаляются оригинал и принадлежащие ему фрагменты/векторы. Одинаковые байты другой загрузки сохраняются до удаления последней ссылки. Истории/отчёты остаются с честным «Файл удалён»; восстановление через UI отсутствует.

`DELETE /api/v0.1/artifacts/{id}` проверяет `artifact:write`/область.204 — подтверждённая очистка,409 — активная индексация,410 — чтение своего удалённого оригинала. При ошибке очистки показан отказ; продолжение обслуживает knowledge-worker, без блокировки других файлов. [Точный контракт](../architecture/25-independent-files.md).

## Созданные документы

PDF/DOCX и другие экспорты регистрируются как обычные файлы с источником/владельцем. Скачивание уже готового экспорта не доказывает новое модельное выполнение. Действующий экспорт предложения описан в [пресейле](presales-pipeline.md). Старый PDF-экспорт обычного tender_radar выведен вместе с модулем; его прежний маршрут не используется.
