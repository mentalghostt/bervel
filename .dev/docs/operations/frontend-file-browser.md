# Просмотр загруженных файлов

Открыть [«Файлы»](http://127.0.0.1:5173/#/files). Список берётся из PostgreSQL в доступной области; каждый пункт адресует самостоятельный неизменяемый оригинал. Файловых редакций и учебных datasets нет.

Выбор показывает доступный preview и скачивание оригинальных байтов. Табличный просмотр — чтение, а не новая версия файла или бизнес-анализ. Смена выбора не подставляет поздний ответ прежнего ID. Открытие/обновление списка не вызывает модель.

Удалённая историческая ссылка сообщает «Файл удалён»; чужая область не раскрывается. Полное удаление требует явного действия/подтверждения. [Форматы/ограничения](files-and-pdf.md), [ID-контракт](../architecture/25-independent-files.md).

Ключ API добавляет серверный прокси, браузер не хранит секрет. Это общий доступ, а не разделение по сотрудникам; [подробнее](frontend-server-access.md).

Проверка: открыть файл, переключить выбор, обновить страницу, скачать и сверить оригинал. Автоматические сценарии — `.dev/tests/frontend-file-browser.cjs`, `frontend-file-preview.cjs`, `test_api.py`. [Команды тестов](docker-local.md).
