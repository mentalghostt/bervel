## Что доступно

На странице загрузки появился раздел «Загруженные файлы». Локальный адрес: http://127.0.0.1:5173/#/files. Навигация меняет раздел внутри приложения и сохраняет состояние текущей загрузки.

Список берётся из PostgreSQL, поэтому включает прежние загрузки. Видны текущая редакция каждого оригинала, название, дата загрузки, размер, число строк и качество последнего результата именно этой редакции. Старый результат не подставляется к новой редакции. Если результата нет, это указано отдельно.

Нажатие на название открывает сохранённые позиции: строка CSV, название, количество, единица и качество. Количество выводится строкой без потери точности. Отсутствующее количество показано как «Не указано». Показанные номера CSV включают строку заголовка; это ссылки на строки источника, а не исходное значение колонки `line`.

Список выдаётся порциями по 20 файлов, строки по 100. Кнопки «Показать ещё файлы» и «Показать ещё строки» запрашивают следующую порцию. Таблицы прокручиваются по горизонтали на узком экране. Доступны сообщения ожидания, ошибки, повтор запроса и пустой список.

## Как устроено

- `GET /api/v0.1/artifacts?cursor=0&limit=20` возвращает только безопасные поля списка и краткую ссылку на результат. Нужны оба права: `artifact:read` и `dataset:read`. Оригиналы и результаты ограничены областью данных ключа.
- Список читает текущую редакцию и связанный результат одним SQL-запросом. Просмотр не создаёт записи аудита или новые результаты.
- Строки читаются существующим `GET /api/v0.1/datasets/{id}/revisions/{revision}/records`.
- По последующему решению владельца ключ добавляет веб-сервер из своего окружения; браузер его не получает. Список загружается сразу, включая открытие после обновления страницы. Результаты старого запроса не появляются после смены выбранного файла или обновления списка. Подробнее: [серверный доступ без ручного ключа](frontend-server-access.md).
- Использованы существующие React, TypeScript и Tailwind. Маршрут использует hash-навигацию без новой библиотеки. Новых зависимостей, миграций и изменений n8n нет.

## Что проверить самостоятельно

Открыть раздел, выбрать прежний файл и сверить его строки. Обновить страницу и убедиться, что загрузки доступны без ввода ключа. Выбрать файл с пропуском количества или оригинал без результата.

Этап не добавляет редактирование, удаление, полноценный вход сотрудников, автоматическую обработку новых документов или предметные согласования. При параллельной загрузке список обновляется по кнопке «Обновить список». Отдельный неизменный снимок списка между страницами пагинации не вводился.
