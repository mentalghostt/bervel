# Симулятор Контур.Закупок для Радара ИИ

Симулятор позволяет проверять штатный поиск, загрузку карточки, сопоставление со складом, сохранение результата и повторный анализ. Код находится в `.dev/scripts/kontur_simulator.py`.

## Данные и ограничения

База содержит 120 000 синтетических закупок за два года. Только 5% относятся к крепежу. Остальные относятся к продуктам питания, лекарствам, топливу, программному обеспечению, ремонту дорог, перевозке, уборке и другим товарам и услугам. В документах обслуживания оборудования встречаются болты. Поэтому запрос по болтам с `Attachments=true` возвращает и закупки услуг.

Карточки включают несколько стадий, валюты, неизвестную цену, смешанные позиции, несколько лотов, сводный состав и разбивку по заказчикам, скрытые характеристики и отсутствие состава. Даты фиксируются при запуске относительно текущего дня. ID устойчивы между перезапусками.

Поиск возвращает `TotalCount`, `PageNumber`, `Items`. Одна страница содержит до 50 закупок. Доступны страницы 0–199 одного запроса, даже если `TotalCount` больше 10 000.

В Docker-окружении `--no-request-quota` отключает накопительные квоты поиска и деталей. `GET /external/v1/limitGroups` возвращает пустой массив. Для именованного прогона Радар использует введённый максимум как потолок и для поисковых страниц, и для подробных запросов. При пустом поле Радар обходит доступную выдачу.

При запуске симулятора в режиме проверки исчерпания квот действуют следующие значения по умолчанию.

| Метод | Бюджет одного запуска |
|---|---|
| `POST /external/v1/search` | 200 запросов |
| `GET /external/v1/purchases/{id}` | 200 запросов |
| `GET /external/v1/limitGroups` | Показывает остаток, отдельной суточной квоты нет |

Общий предел скорости составляет 5 запросов в секунду. Превышение скорости или исчерпание соответствующей квоты даёт HTTP 429. Неизвестный ID даёт 404, неподходящий ключ — 401, некорректные параметры — 400. Перезапуск процесса сбрасывает обе квоты. Автоматическое суточное обновление в симуляторе отсутствует.

Поддерживаются `Text`, `Exclude`, `StrictSearch`, `Attachments`, даты публикации и окончания подачи, стадии, диапазон цены, включение неизвестной цены и иностранной валюты, `RegionIds`, `Laws`, `CategoryIds`, `IncludeInns`, `ExcludeInns`. Прочие параметры получают HTTP 400. Поиск сопоставляет целые слова, поддерживает запятую как «ИЛИ», пробел как «И», префикс `*` и ограниченный словарь словоформ крепежа. Закрытые алгоритмы ранжирования, морфология и индекс документов Контура полностью не воспроизводятся. Эквивалентность результатов поиска на реальной базе не заявляется. Форматы проверены по сохранённой OpenAPI-схеме от 29 октября 2026 года. Открытая справка описывает правила поиска веб-сервиса, отдельные детали поиска внешнего API требуют проверки у провайдера. [Схема](../../local/kontur-api-2026-10-29/openapi.json), [справка Контура](https://support.kontur.ru/zakupki/49207-zapros).

## Подключение

Для обычного локального запуска из корня проекта в PowerShell выполните команду.

```powershell
& .dev/local/core-stage-3.1/venv/Scripts/python.exe .dev/scripts/kontur_simulator.py
```

Для запуска в существующем Docker-окружении используется дополнительный Compose-файл.

```powershell
docker compose -f compose.yaml -f .dev/docker/compose.kontur-simulator.yaml up -d --no-deps kontur-simulator api worker-ai-tender-radar
```

Перед этим образы API и worker должны содержать поддержку параметра `BERVEL_AI_RADAR_KONTUR_BASE_URL`. При установленном окружении с отдельными версиями образов следует использовать подготовленный для него пакет установки, сохраняющий фактические образы и настройки.

`BERVEL_AI_RADAR_KONTUR_BASE_URL=http://kontur-simulator:8765` выбирает симулятор только для Радара ИИ. При запуске Python вне Docker можно указать `http://127.0.0.1:8765`. Клиент допускает только локальные HTTP-адреса и имя сервиса `kontur-simulator`. Он автоматически использует ключ `bervel-kontur-simulator`. Ключ провайдера остаётся доступен только клиенту боевого источника. Переадресация запрещена. При недоступном симуляторе задание завершается ошибкой соединения.

Для самостоятельных HTTP-запросов передавайте заголовок `X-Kontur-Apikey: bervel-kontur-simulator`. Сервис внутри Docker доступен в сети приложения, порт на хост не публикуется.

Алгоритм Радара ИИ сохраняет окно из трёх поисковых страниц и выбор одного следующего необработанного ID. Симулятор воспроизводит доступную ёмкость источника, а объём конкретного задания задаёт существующий алгоритм радара. Тестовый источник сохраняется в карточке, результат получает `mock=true`, заголовок содержит «Симуляция». Повторный анализ требует тот же источник.
