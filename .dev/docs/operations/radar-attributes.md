# Проверка радара с атрибутами

Основной экран: http://127.0.0.1:5173/#/radar. Новый запуск без отдельного файла экономики использует версию1.6. Исходник склада выбирается в «Данные по складу»; продажную цену задаёт тендер, склад содержит себестоимость.

## Что проверить в интерфейсе

1. Выбрать Контур API, склад и параметры поиска; запустить анализ.
2. В результате показывается единый список, у каждой проанализированной закупки готовность к участию и экономическая выгода.
3. Переключить сортировку между полностью закрываемыми и наиболее выгодными.
4. Указать включительные границы готовности0–100 и выгоды−100–100. «Сбросить диапазоны» возвращает полную выдачу, включая неизвестные показатели с причинами.
5. Раскрыть подробности: покрытые/требуемые штуки, расчёт остатков, исходные единицы и цены тендера, себестоимость и прибыль.
6. Скачать PDF. Исторические отчёты показывают прежние результаты, без придуманных новых процентов.

Неполная готовность рядом со100 не округляется в полностью закрытую закупку. Неизвестный показатель отличается от0. Если API не раскрывает цены всех позиций, полная выгода не подменяется складскими ценами или частью закупки.
