# Подготовка файлов для ИИ

Загрузить оригинал в [«Файлах»](http://127.0.0.1:5173/#/files), открыть его и проверить блок подготовки. Байты доступны для скачивания сразу; готовность загрузки не означает готовность поиска.

`GET /api/v0.1/artifacts/{id}/knowledge` показывает состояние и счётчики одного файла. `POST /api/v0.1/artifacts/{id}/knowledge/resume` с `{}` продолжает незавершённые порции. `ready` означает покрытие извлечённого содержимого; `partial` — ограничение чтения, `unsupported` — отсутствие декодера при сохранённых байтах. Расширение файла не создаёт декодер.

При ошибке устранить указанную причину и явно продолжить подготовку. Готовые фрагменты не отправляются заново. Остановленный knowledge-worker не запускается открытием страницы; его включение — отдельная операция по задаче.

Провайдер embeddings задаётся серверным окружением; ключи не публикуются. Смена пространства требует совместимости или отдельного плана переиндексации, без скрытого повторного расхода модели. Используется PostgreSQL/pgvector, дополнительного Qdrant нет.

Поиск возвращает кандидатов, не полную проверку документа. В явно обозначенном lexical/page-режиме ассистент может читать доступные тексты без работающих embeddings; ограничения остаются видимыми.
