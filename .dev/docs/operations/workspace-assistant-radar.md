# Работа с разделами BERVEL

Локальный адрес — [127.0.0.1:5173](http://127.0.0.1:5173/). [Карта экранов](../architecture/24-workspace-assistant-radar.md) соответствует `App.tsx`; наличие исходника не доказывает установку нового поведения.

В [«Файлах»](http://127.0.0.1:5173/#/files) загрузить/открыть/скачать оригинал. Каждая загрузка/правка создаёт отдельный файл. Готовность для ИИ проверяется отдельно. [Просмотр/удаление](files-and-pdf.md), [знания](shared-knowledge.md).

В [«Ассистенте»](http://127.0.0.1:5173/#/chat) создать диалог или открыть сохранённый. Действия имеют квитанции: успех, отказ и unknown различаются. Ссылка на документ появляется после регистрации файла; текст модели не подтверждает эффект. Удаление чата не удаляет документы/анализы/обращения. Расчёты CSV/XLSX выполняются сервером с явными ограничениями. Для микрофона нужен loopback/HTTPS и настроенное распознавание. [Данные и native web](../architecture/26-assistant-data-and-native-web.md).

В [«Настройках предприятия»](http://127.0.0.1:5173/#/company-settings) находятся общие каталог/склад/производство. [Радар ИИ](http://127.0.0.1:5173/#/ai-tender-radar) работает с профилями: обновление, авторежим и метрики имеют разные эффекты. [Инструкция](ai-radar-profile.md). Ремонт 23document-warning ещё не завершён; полный refresh не заменяет адресный повтор.

В [«Пресейл-конвейере»](http://127.0.0.1:5173/#/presales) комплект файлов создаёт одно обращение с редакциями, статусами, ценами и экспортами. [Инструкция](presales-pipeline.md). Новый попап настроек подготовлен, не установлен.

[«Проверка»](http://127.0.0.1:5173/#/inspection) ведёт настоящий native Codex thread с командами и доступом по задаче. [Полномочия/Stop](inspection-chat.md). Досылка в активный thread подготовлена отдельно, её установка отложена.

[«Обращения»](http://127.0.0.1:5173/#/tickets) хранят внутренние тикеты; это не отправка клиенту и не клиентская редакция пресейла. Анализ/экспорт не означают резерв, подпись или запись во внешнюю систему.
