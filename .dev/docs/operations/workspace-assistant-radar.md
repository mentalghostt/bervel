# Файлы, радар и универсальный ассистент

Обновление файлового контракта28.10.2026 подготовлено в исходниках и проверено на изолированно восстановленных данных; основная установка ещё не подтверждена. Ниже описана новая работа файлов после установки. [Контракт и статус](../architecture/25-independent-files.md). Прежние UI/chat-возможности установлены отдельными задачами.

Интерфейс и ассистент обновлены28.10.2026 в существующем локальном Docker-окружении. Основной адрес: [BERVEL](http://127.0.0.1:5173/). Для микрофона открывайте этот loopback-адрес либо HTTPS.

## Подготовить и запустить радар

1. На странице «Файлы» нажмите «Загрузить файл». В открывшемся окне выберите файл или перетащите его в область загрузки. Укажите назначение: выгрузка тендеров, данные по складу либо экономика/производительность. Уже загруженному файлу назначение меняется в компактной шапке просмотра.
2. Дождитесь плашки «Готов к ИИ анализу» справа от названия. Ошибки/частичная обработка требуют исправления; такой файл в радар не допускается.
3. В радаре выберите по одному файлу каждого назначения. Задайте цены от/до, запас дней до закрытия, фокус, нехватку и маржу. Нажмите отдельную кнопку «Подобрать тендеры».
4. Результат и история находятся в соседних колонках и растут вниз по странице. Просмотр запуска не меняет сортировку истории по дате создания. Откройте причины и расчёты конкретной закупки. PDF содержит весь сохранённый отчёт; неполный анализ явно обозначен.

Цена и срок подачи отсеивают закупки до модели. Отсутствующие важные сведения требуют проверки. Любая нехватка требует человека, даже если проходит допуск. Каждый тендер проверяется отдельно; несколько положительных результатов не означают возможность исполнить их одновременно.

Экономика сейчас принимает UTF-8 CSV с колонками `sku,unit,currency,sale_price,unit_cost,fixed_cost,logistics_cost,packaging_per_unit,capacity_per_day,production_lead_days,delivery_lead_days,data_kind`. Одна строка на SKU. `data_kind` одинаковый во всём файле: mock либо reported. Неизвестное число оставляйте пустым, известный ноль пишите0. Цены/затраты должны включать все необходимые начисления в одной валюте. Стоимость и логистика распределены на отдельный SKU в одном тендере. Пример `bervel-economics-production-MOCK.csv` демонстрационный: реальные цены и мощности завода не подтверждены.

Структура склада: UTF-8 CSV, обязательны `sku,product,free_quantity,unit`; технические поля соответствуют существующему образцу склада. Номер тендера не является единственным идентификатором: разные карточки источника могут иметь один номер. Охват смотрите по input/accounted rows.

## Поручить работу ассистенту

Ассистент самостоятельно находит данные по смыслу и назначению. Можно написать «Найди нашу продукцию в базе», «Составь PDF по продукции на складе» или «Найди трёх российских конкурентов по нашей продукции со ссылками на официальные сайты». Имя загруженного файла заранее указывать не требуется. Для итогов CSV/XLSX используются полные таблицы, единицы измерения разделяются; демонстрационные данные обозначаются явно.

Веб-поиск выполняется штатным Codex. Ключ xAI относится только к голосовому вводу и для интернета не нужен. Составной поиск может занять несколько минут; выполненные шаги видны в «Действиях». При ограничении частоты429 показывается отдельное сообщение. Уже созданный файл остаётся в карточке даже при более позднем сбое; автоматически повторять создание не требуется.

Примеры: «Запусти тендерный радар с последними готовыми данными, минимальная маржа20%», «Скачай PDF запуска…», «Создай документ PDF…», «Нарисуй схему…», «Создай обращение разработчикам: …». Явно запрошенные действия выполняются без повторного согласования; при недостаточных данных ассистент уточняет объект.

Карточки под ответом содержат сохранённый документ, запуск или обращение. Запуск отслеживается в карточке; PDF появляется после первого сохранённого отчёта, с предупреждением при неполном анализе. Новый диалог не отменяет уже созданное задание. Неизвестный исход не повторяется автоматически.

Список файлов и команды выполняются без предварительного поиска по содержимому. При вопросе по документу ассистент читает нужный файл; под ответом остаётся одна ссылка на каждый использованный файл. Она открывает точный источник в разделе «Файлы». Старые чаты сохраняются, повторные фрагменты одного источника отображаются одной ссылкой.

В «Обращениях» можно открыть и дополнить черновик. Статус «Отправлено» зарезервирован контрактом, но система отправки отсутствует и кнопки отправки нет.

Чаты доступны в списке слева. «Новый диалог» начинает отдельную переписку; старые чаты можно открывать из списка. «Удалить» убирает только выбранную переписку и её контекст. Созданные документы, запуски радара и обращения остаются в своих разделах. Удаление недоступно во время обработки ответа. Если исход удаления неизвестен, повторите ту же кнопку: новый ключ и повторное выполнение действий не создаются.

## Подключить голос

В «Настройках» → «xAI: голосовой ввод» введите ключ для распознавания речи. Значение не показывается повторно и не нужно в сообщениях чата. xAI используется только для голоса. Веб-поиск выполняет штатный Codex через выбранное подключение; отдельный ключ xAI для поиска не нужен.

Микрофон записывает речь, после остановки появляется редактируемый текст. Проверьте числа и отправьте сообщение обычной кнопкой. Отмена не отправляет запрос в чат. При отказе браузера в доступе текстовый ввод остаётся доступным.

## Загрузить или изменить файл

Каждая загрузка создаёт самостоятельный файл, даже если имя или байты совпадают. При неизвестном исходе повторяется та же команда с прежним ключом. Если ассистенту поручено изменить документ, он сохраняет результат отдельным файлом; исходник остаётся до явного удаления. Ссылки чата и сохранённых запусков продолжают вести к тому же ID.

Старая закладка с номером редакции покажет «Ссылка устарела». Старая неизвестная команда радара с неподдерживаемыми ссылками блокируется с сохранением ключа; сначала нужно сверить прежний результат в истории. Автоматического нового запуска нет.

## Удалить файл

Полное удаление убирает оригинал и относящиеся только к нему данные поиска. Чаты и отчёты остаются; переход к источнику показывает «Файл удалён». Другие файлы, в том числе использующие такие же физические байты, сохраняются. Настоящую исходную папку пользователя в Downloads приложение не удаляет: удаляется загруженный экземпляр в хранилище BERVEL.

Технические границы: [архитектура](../architecture/24-workspace-assistant-radar.md). Доказательства проверок находятся в `.dev/local/platform-upgrade-2026-10-27/`; deploy/backup/evaluation helpers фиксируют конкретную операцию и не предназначены для слепого повторного запуска.
