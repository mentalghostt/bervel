# Файлы и PDF — два согласованных этапа

Режим АВТОНОМНО по запросу владельца. Корень C:/OSPanel/home/bervel.local, Personal, основная ветка core; Git только чтение, прежние изменения сохраняются. Рабочие материалы в .dev. VPN/MOX/auth/config/OSP не менять.

## 1. Ширина и фиксированный PDF

- Убрать max-w-6xl из оболочки и страниц, сохранить поля и ограничения длины отдельных текстов.
- Экспорт завершённого сохранённого запуска через авторизованный GET /radar/runs/{id}/report.pdf. Рендеринг вне бизнес-логики, без нового LLM/изменения отчёта/БД.
- Один шаблон BERVEL v1: A4, палитра существующего интерфейса, встроенные Noto Sans Regular/Bold с лицензией, фиксированная иерархия/поля/колонтитулы, сводка, все категории/записи и источники. Содержание из отчёта экранировать, ссылки только HTTP(S). ReportLab pinned; runtime ресурсы вне .dev и внутри wheel.
- Проверки: RED/GREEN API, права/scope/незавершённый запуск, настоящий PDF/кириллица/встроенные шрифты/переносы, повторяемость одинакового результата; скачивание настоящего сохранённого отчёта, PNG визуальная проверка.

## 2. Файлы

- Заголовок и меню «Файлы». Desktop grid1:2, мобильный последовательный список/просмотр; без общего max-width.
- Просмотр проверенного оригинала отдельно от учебного dataset: изображения/PDF визуально; произвольный CSV с собственными колонками; UTF-8 текст, DOCX/XLSX как ограниченное текстовое представление. Неподдерживаемые форматы — явный статус/скачивание. Учебный обработанный результат остаётся доступен отдельно.
- Узкий адаптер preview + явный DTO, существующие artifact permissions/scope/hash. CSV ограничен строками/колонками/размером, пагинация/предупреждения; декодирование без исполнения HTML/формул. Browser blob URLs только из авторизованного fetch, освобождение при смене файла; поздние ответы не заменяют новый выбор.
- Проверки: RED/GREEN произвольный CSV/даты и точные числовые строки/кодировки/границы/доступ/повреждение; browser image/PDF/table/switch/retry/mobile; полный подходящий backend/frontend regression, независимое ревью, build и проверка по реальному адресу. Fingerprints прежних данных/auth/config после равны до.

Основания: ADR0001/0004/0005; бизнес-правила радара, данные/стадии и настройки модели не меняются. Результаты фиксируются в docs/quality/files-pdf-report.md.

Оба этапа выполнены. Финал:175 backend/41 browser, build/lint, независимое ревью3 исправленных P2, настоящий PDF/страницы оригинала/CSV/PNG/XLSX на1600/390. При визуальной проверке native PDF заменён локальным PDF.js, исправлен MIME worker; это уточнение способа реализации внутри разрешённого автономного этапа. Все19 таблиц и внешние auth/config совпали до/после. Подробности и ограничения — ../quality/files-pdf-report.md.
