# Замена фонового запуска: план реализации

**Цель:** сохранить фоновый CSV на Python/PostgreSQL, убрать зависимости n8n/Redis и проверить сохранность данных и интерфейса.

**Основание:** явное решение владельца от 22 октября 2026. [Устройство](../architecture/15-python-background-processes.md).

**Ограничения:** существующая папка `C:/OSPanel/home/bervel.local`, ветка `core`, Git только для чтения; прежние незакоммиченные изменения сохраняются. VPN и Open Server не меняются. Новых библиотек нет. Материалы разработки остаются в `.dev`.

1. **Исполнение и API.** Сначала проверки новой очереди и прежних гарантий, затем замена `ProcessService`, репозитория и маршрутов; Python worker и совместимая миграция. Проверить реальные PostgreSQL-транзакции, блокировки, повторы и восстановление.
2. **Запуск и удаление зависимостей.** Compose, настройки, CLI, инструменты резервирования и текущие инструкции переводятся на Python worker. Снять старые сервисы, сохранив их данные. Проверить сборку без старых переменных и сервисов.
3. **Регрессии и сохранность.** Полный серверный набор, сборка/линтер, браузерные и живые сценарии с отдельной тестовой БД. Сверить прежние строки, редакции и оригиналы с резервной копией; проверить очередь через настоящий worker и отказ исполнителя. Независимое ревью перед отчётом.

Особое внимание: заброшенная блокировка в пуле соединений; повтор восстановления в гонке; устаревшая попытка; историческая версия процесса; запуск резервирования после пересборки образа.
