# Перестройка Python BERVEL

Задача выполняется автономно в C:/OSPanel/home/bervel.local, ветка core, без изменений Git. Согласованный дизайн: модульный монолит с портами и адаптерами, без нового движка модулей и зависимостей. Внешние URL, поведение, данные и линейные revision IDs сохраняются.

1. Baseline: сохранить состояние файлов, Git, таблиц/оригиналов и HTTP-контракт; выполнить существующие backend-тесты на текущих исходниках.
2. Шаблон и правила: минимальный пакет в .dev/templates/module; закрепить роли и правила в обоих файлах инструкций.
3. Платформа и чат: core/{api,infrastructure,migrations}, modules/chat; внешняя композиция app_setup.py. Общая память документов отделена от хранения чата. Проверка: существующие тесты и ограничения импортов.
4. Радар и document_review: API/таблицы/адаптеры принадлежат модулю; явные типизированные операции/порты; однотипное ручное подключение в bootstrap. Общие receipts обеспечивают прежнюю транзакцию, без private-вызовов. Миграция 0007 содержит собственный исторический DDL. Проверка: конкурентные команды, rollback, scope, свежая миграция и соответствие таблиц.
5. Поставка и runtime: собрать wheel без .dev, проверить ресурсы и полный backend suite. Пересоздать только затронутые API/worker/migrate из одного образа, сохранить volumes. Проверить прежние файлы/чат/радар/PDF, новые фоновые сценарии и неизменность прежних строк. Краткая карта и отчёт в .dev.

Риски проверки: потеря ресурсных файлов wheel; несовпадение исторического DDL; изменение OpenAPI при переносах; нарушение атомарности повторов; случайная зависимость core от модулей/.dev. Каждый проверяется отдельно. Изменения соседних чатов сохраняются; source-before.json содержит тексты исходных runtime-файлов для сравнения именно с началом этой задачи.

Документация библиотек: Context7 вызван, но подключённый tool недоступен модели; использована официальная документация SQLAlchemy MetaData, Alembic Operations, setuptools package-data и FastAPI APIRouter.

Выполнение завершено 23 октября 2026: все пять этапов пройдены, 183 backend PASS, реальные MOX chat/radar/PDF и сохранность прежних данных подтверждены. Финальные результаты — `.dev/docs/quality/python-layout-report.md`; рабочий журнал — `.dev/local/python-layout/ledger.md`. По уточнению владельца имя точки сборки — `app_setup.py`.
