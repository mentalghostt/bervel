# Возможности универсального ассистента

Пользователь подтвердил автономное выполнение всех трёх этапов. Корень: C:/OSPanel/home/bervel.local, Personal, основная ветка core. Git только чтение. xAI используется исключительно для распознавания голоса; веб-поиск выполняется штатным Codex.

## Подтверждённые причины

Запрос PDF от28.10 успешно выполнил file.read по11 строкам mock-склада, затем следующий модельный запрос завершился HTTP429 (подтверждено task_complete.error SDK). Генерация файла не вызывалась. Общий MODEL_FAILED скрывает эту причину. Native web-прокси переписывает tools/tool_choice, получил400 upstream_rejected и переключается на xAI. Ассистент не имеет общей команды поиска данных и просит имя файла, уже присутствующего в каталоге.

## Решение

1. Сохранить текущий провайдер и SDK. Классифицировать429 отдельно; ограниченно повторять только явно отклонённый запрос модели, с ожиданием и общим deadline. Не повторять успешные/неизвестные действия приложения. Сохранённый документ доступен и при более позднем сбое модели. Рендеринг PDF/DOCX остаётся серверным.
2. Ассистент сам ищет сведения через существующую scoped PostgreSQL-базу знаний, выбирает релевантные файлы, читает страницы. Числовые итоги вычисляются детерминированно по полным табличным данным, если такой итог запрошен. Никакого произвольного SQL модели. Полнота/ограничения/ID источника сохраняются, mock не превращается в фактический склад. Нерелевантные документы не читаются для приветствий/метаданных/команд.
3. Native web Codex: сначала исследовать реальный запрос SDK и ответ шлюза, исправить доказанную несовместимость. Прокси наблюдает native события/цитаты, не подменяет источники текстовыми URL. Удалить xAI web fallback и его UI-описания/тесты; voice сохранить. Не менять VPN, внешние MOX auth/config/CA и выбранную модель. Если шлюз объективно не поддерживает поиск, зафиксировать точный внешний блокер; не имитировать успех.

## Доставка

Исходники уже содержат прежний подготовленный переход0013, основная БД остаётся0012. Установка возможна только согласованным пакетом API/workers/frontend после свежего backup и проверки миграции на восстановленной БД. Не запускать старые deploy helpers слепо. Не переносить проект и не удалять чужие материалы.

## Приёмка

Тесты429, отсутствия повторных эффектов, scoped поиска, полной/страничной выборки, точных расчётов и запрета xAI web. Живой PDF по11SKU с видимой mock-отметкой; самостоятельное получение продукции без вопроса об имени файла; штатный web с реальными native событиями/источниками. Сохранность прежних файлов, векторов, истории и радара проверяется отдельно от тестовых новых записей.
