# Возможности ассистента: план реализации

> Исполнение: dispatching-parallel-agents для независимых Node/Python частей, интеграция и проверка основным агентом. Пользователь подтвердил автономный режим; промежуточная приёмка не требуется. Git-запись запрещена.

**Цель:** ассистент создаёт документы из данных, самостоятельно находит их в PostgreSQL и пользуется штатным web Codex; xAI только голос.

**Архитектура:** существующий typed planner → scoped сервисы → сохранённые квитанции. SDK и модельный транспорт отдельно от бизнес-действий. Новые зависимости не предполагаются.

**Стек:** существующие Python/FastAPI/PostgreSQL/ReportLab, Node24/Codex SDK0.163, React.

**Спецификация:** 2026-10-28-assistant-capabilities-design.md.

## Ограничения
