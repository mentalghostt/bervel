Продолжение автономно согласованной задачи. Пользователь отдельно потребовал сначала корректные падающие тесты, затем реализацию. Корень C:/OSPanel/home/bervel.local, Personal/core. Git только чтение; VPN, Open Server Panel, внешние ключи и MOX-подключение не меняются. xAI остаётся исключительно голосом.

## Подтверждённая причина

Повторный запрос `проанализируй наших конкурентов и составь документ пдф с анализом их производства` остановился на knowledge.search с EMBEDDING_REGION_UNAVAILABLE. Готовые тексты и индекс в PostgreSQL доступны, но каждый поиск требует внешнего query embedding. AssistantActions сохраняет failed receipt и выбрасывает CoreError; ChatService превращает любой такой отказ в failed всего диалога, не предлагая модели допустимый альтернативный путь.

## Проверяемое поведение

- Известный внешний отказ эмбеддингов переводит поиск по сохранённым текстам в честно обозначенный лексический режим. Scope/deleted/model/integrity проверки не ослабляются; векторы не смешиваются и не переиндексируются. Даже пустой результат сохраняет режим и предупреждение.
- Ожидаемый сбой инструмента передаётся планировщику как типизированная failed-квитанция. Модель может прочитать файл страницами, исправить заведомо отвергнутое имя или завершить ответ с понятным ограничением. Один и тот же неудачный вызов автоматически не повторяется.
- Ошибки доступа и неизвестные исходы останавливают дальнейшие действия. Ошибка после фактического сохранения файла не считается доказательством отсутствия эффекта: receipt unknown, повтор запрещён.
- Если финальный вызов модели недоступен после создания файла, сохранённая карточка остаётся доступна, ответ объясняет ограничение без ложного утверждения о полном успехе. Известный отказ провайдера до действий также получает понятное сообщение в диалоге, без выдуманного результата.
- Полный сценарий требует физический PDF, фактические источники и native web receipts, а не только совпавшую строку или карточку kind=file.

2. Минимально исправить KnowledgeService/PostgresKnowledgeRepository/DocumentMemory. Явный результат поиска содержит sources/mode/notice, существующее list-чтение сохраняет совместимость.
3. Исправить исполнение ChatService/actions/receipts: безопасные failure receipts, запрет повторных эффектов, честные conversational ответы.
4. Полная регрессия, независимое ревью, живой контроль точного пользовательского запроса на проверенной копии/пакете, затем установка только необходимых служб после idle/backup. Не запускать сохранённые старые неизвестные команды повторно.
5. Проверить основной runtime, файл/скачивание/источники, сохранность данных; сообщить фактический результат и ограничения.
