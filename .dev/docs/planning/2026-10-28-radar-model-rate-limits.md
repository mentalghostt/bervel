# Ограниченные повторы HTTP 429 и остановка радара

> Исполнение: текущий агент выполняет согласованный этап в существующем корне. Git только читается. Режим обычный: после проверки исходников — приёмка пользователем перед установкой.

**Цель:** пережить временное ограничение провайдера, не отправлять следующие порции после исчерпания попыток и не повторять запросы с неизвестным исходом.

**Архитектура:** транспорт Codex повторяет только явно отклонённый HTTP 429 на `/responses`. При окончательном `MODEL_RATE_LIMITED` прикладной сервис радара сохраняет частичный отчёт и завершает запуск. Товарные правила, складская арифметика и экономика не меняются.

**Основание:** пользователь выбрал ожидание `Retry-After`, иначе 10/20/40 секунд, максимум три повтора. Лимит суммарных пауз 70 секунд. При большем требуемом ожидании запрос раньше срока не повторяется. Ошибки квот/оплаты, тайм-ауты, сетевой обрыв и успешные потоки не повторяются.
