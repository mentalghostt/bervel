## Интерфейс

Графитовые поверхности, мятный акцент и локальные шрифты сохраняются. Меню становится горизонтальным верхним, без b., РАБОЧАЯ ОБЛАСТЬ, BERVEL Workspace и Файлы · решения · действия. На узком экране допускается перенос пунктов, без горизонтального переполнения страницы.

Файлы: список слева около300px на desktop, сохраняет ограниченную высоту со своей прокруткой. Просмотр справа имеет ту же минимальную высоту и растёт по содержимому без внутренней вертикальной прокрутки. Для широких таблиц допустима горизонтальная прокрутка, текст ячеек не прячется за вертикальным скроллом. На мобильном блоки последовательные. Общая строка «Все файлы» имеет кнопки «Загрузить файл»/«Обновить» справа. Загрузка открывается нативным modal dialog с drag/drop и выбором назначения; состояние неизвестной попытки не теряется при закрытии. Удаление — внизу справа каждой карточки списка, без вложенных button. Существующий контракт полного удаления/подтверждения сохраняется. Шапка просмотра компактна: имя, состояние, редакция/размер, назначение, скачать. Нет большого отдельного status-блока для готового файла. Ошибки обработки/resume остаются доступны.

Радар: результаты и история растут вниз без внутренних вертикальных скроллов. История всегда отсортирована по created_at убыванию; чтение/выбор существующего запуска обновляет его на месте. Машинные поля, неполнота/ошибки и PDF-происхождение не удаляются. Компактные фактические данные/пометки отдельных результатов сохраняются. Обычный отчёт и сохранённые параметры позволяют объяснить результат.
