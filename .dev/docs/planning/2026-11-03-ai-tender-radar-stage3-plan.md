# Раздел и установка Тендерного радара ИИ

**Цель** — запустить анализ реального тендера из нового пункта меню BERVEL и открыть сохранённый результат.

**Спецификация** — [Тендерный радар ИИ](2026-11-03-ai-tender-radar-design.md), согласованный этап 3.

- [x] Подключить список карточек и команду пересчёта по ID закупки. Проверить права, идемпотентность, загрузку карточек страницами и сохранение предыдущего результата при сбое пересчёта.
- [x] Добавить отдельный экран с выбором складского CSV, поисковой фразой, запуском и состоянием фонового задания. Проверить восстановление после перезагрузки и неизвестного ответа при отправке.
- [x] Показать покрытие, выгоду, причины отсутствия данных и позиционные доказательства. Прогнать браузерные проверки настольной и мобильной раскладки, отсутствие ошибок JS и переход из меню.
- [x] Собрать образы на базе действующих компонентов. Сверить чужие изменения, сохранить резервную копию БД и проверить восстановление. Установить миграции, обновить API и frontend, запустить выделенный worker.
- [x] Через рабочее меню запустить один тендер из Контура, дождаться анализа и сверить карточку с серверным результатом. Проверить доступность карточки после перезагрузки.

## Проверки установки

Исходная сборка frontend совпала с действующей по всем 311 файлам. API собран поверх действовавшего образа с добавлением только нового модуля, миграций и строк подключения. Резервная копия БД восстановлена в отдельной PostgreSQL, миграции `0020`–`0022` проверены на восстановленных данных перед установкой.

Прошли 48 целевых и регрессионных серверных тестов. Браузерные тесты на ширинах 1440 и 390 px проверили меню, неизвестный ответ на POST, повтор команды, восстановление задания, показатели и доказательства. TypeScript, Vite и линтер завершились успешно. В линтере остались прежние предупреждения соседних компонентов.

Частично подтверждённые складские кандидаты теперь тоже передаются Codex. Сервер разрешает засчитать только SKU, у которых проверены все обязательные требования. При отдельном обновлении обработчика сохранён API, который параллельная задача обновила до объединённой версии. Проверено, что остальные контейнеры на этом шаге сохранили свои ID.

## Рабочий прогон

Из меню BERVEL запущен тендер «Метизная продукция» (`GPPO1041045`, задание `b3cc8c6c-bbfa-4a20-8666-a341388e7ece`). Из Контура получены 32 позиции, склад прочитан целиком, 3 076 строк. Codex CLI вернул структурированный ответ без ошибок. По этому тендеру подтверждённых складских совпадений нет, поэтому покрытие и выгода остались неизвестными. Карточка показала оба отсутствующих значения, причины и все 32 позиции. После перезагрузки карточка доступна с тем же результатом. Доказательства в `.dev/local/ai-tender-radar-stage3/live-check.json` и `.dev/local/ai-tender-radar-stage3/live-ai-radar.png`.
