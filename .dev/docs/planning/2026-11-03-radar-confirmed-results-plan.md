# План радара с целью по подтверждённым результатам

Режим АВТОНОМНО. Существующий корень C:/OSPanel/home/bervel.local, Personal, core. Рабочие файлы редактируются на месте. Git только для чтения.

Цель нового запуска через Контур — до N тендеров, где подтверждена хотя бы одна позиция и покрывается положительное количество. Неизвестный общий процент допускается при подтверждённой отдельной позиции. Поиск и получение карточек имеют отдельный ограниченный бюджет. Исторические команды и файлы сохраняют свой контракт.

- [x] Разобрать реально встреченные обозначения резьбы одним разбором для поиска и проверки. Проверить оба порядка шага и длины, поле допуска и обычные обозначения.
- [x] Выбирать полные карточки из общей дедуплицированной выдачи. Складские размеры и стандарты из заголовка и фрагментов помогают определить порядок. Полные объекты остаются источником доказательства. Получить неизменяемый снимок с отдельным бюджетом до 100 карточек для цели 20.
- [x] После каждой проверенной карточки учитывать только подтверждённое покрытие. Остановить проверку при достижении цели, сохранить прогресс и объяснить меньший результат при исчерпании доступных кандидатов. Не повторять сохранённые вызовы. Развести старые и новые запросы через явную версию запуска.
- [x] В интерфейсе показывать цель, ход проверки, номера и названия позиций. Сохранить совместимость со старыми отчётами и привязку к исходным объектам. Проверить экспорт PDF.
- [ ] Проверить парсер, порядок загрузки, контроль с совпадением после первых 20 карточек, восстановление после сбоя, API и UI. Установить точечные изменения поверх текущих образов приложения.

Решение: загрузка единого отсортированного снимка перед проверкой позволяет сохранить текущую модель восстановления без повторного платного запроса. Размер снимка и расход поисковых запросов ограничены отдельно. Анализ останавливается на целевом количестве; загрузка снимка имеет собственный бюджет.
