# 2. Настройки предприятия и экспериментальные продукты

Результат: пользователь один раз задаёт склад, продукцию и мощности; радар использует сохранённые настройки автоматически.

**Inputs.** Текущий складской файл, `Product[]`, отдельная таблица `ExperimentalProduct[]`, общий `include_experimental`, переключатель `enabled` каждой строки; `ProductionCapability[]`, `ResourceAvailability[]`, политика оценки. Производственные поля можно импортировать дополнительными колонками склада, но они не обязательны для старого CSV. Нулевая складская доступность не исключает продукцию из каталога.

**Outputs.** Версионный `SettingsSnapshot`; предварительный просмотр импорта с происхождением полей; поисковые запросы из активной продукции. Файл — источник импорта, сохранённый снимок — единый вход расчёта.

**Preconditions.** Доступ к настройкам и файлу в текущей `data_scope`; файл полностью прочитан. Неоднородные названия и атрибуты извлекаются LLM только там, где не работает известный формат, и подтверждаются до сохранения.

**Postconditions.** В БД атомарно создан новый снимок. Экспериментальные позиции хранятся отдельно; участвуют в поиске и сопоставлении только при общем и построчном включении. Ручные исправления имеют происхождение и не теряются при импорте без видимого разрешения конфликта. Прежние прогоны сохраняют прежний профиль.

**Error cases & Invariants.** Обычный каталог — официальная продукция завода; поле прежнего выпуска удалено. Экспериментальная продукция независима, выключена по умолчанию; её включение не создаёт производство и не активирует отключённую обычную строку. Старые поля принимаются необязательно для точного повтора старых команд. Ошибки SKU, единиц, мощности, валюты и дубли показываются по строкам; нет молчаливого усечения. При превышении лимита поисковой фразы запрос разбивается на части с общим бюджетом и дедупликацией; отключённая категория не должна проходить содержательный отбор по собственному совпадению.

**Acceptance Criteria.** GIVEN экспериментальная строка и выключенный общий переключатель WHEN новый запуск THEN эксперимент исключён; WHEN явно включены оба переключателя THEN он участвует в поиске и анализе; GIVEN официальная деталь без удалённых полей с нулевым остатком THEN она доступна для оценки допроизводства; GIVEN неполные производственные факты THEN уверенная выполнимость не заявляется; GIVEN старый CSV/команда THEN импорт/точный повтор работают, исторический снимок не изменяется.

**Реализация и проверка.** Новый узкий модуль `src/bervel/modules/company_settings/` (`models.py`, `service.py`, `api.py`, `infrastructure/repository.py`); `frontend/src/CompanySettingsPage.tsx`, `companySettingsApi.ts`. Подключение через существующий composition root. В радаре — потребляющий контракт чтения снимка, расширение импорта и поиска. Проверки `.dev/tests/test_company_settings.py` и `.dev/tests/frontend-company-settings.cjs`. Конкретную внешнюю интеграцию склада не реализовывать до выбора сервиса.
