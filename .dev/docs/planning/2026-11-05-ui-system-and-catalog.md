# Единый интерфейс и официальный каталог

Продолжение замечаний к предыдущему автономному выпуску. Корень C:/OSPanel/home/bervel.local, Personal, основной checkout core. Все артефакты в .dev/local/ui-system-2026-11-05/. Git только чтение, VPN/OSPanel не менять, Контур только симулятор.

## Требования и результат

1. Обычная продукция — официальный каталог; отдельное «Ранее производили» и подтверждение прежнего выпуска не нужны. Нормы, затраты, сырьё и подтверждение именно мощностей остаются проверяемыми фактами. Экспериментальная продукция независима, её связь с обычной удалена; участие только при явном include_experimental и enabled строки. Новые профили по умолчанию include_experimental=false.
2. В настройках выровнены контролы строк, удалены номера разделов, строка версии/UUID и пояснения без действия. Поля/статусы, необходимые для правильного ввода и восстановления ошибок, сохранены.
3. Во всех разделах удалены вводные текстовые шапки. Навигация определяет раздел; функциональные действия сохраняются компактным toolbar. Единые расстояния, поля, кнопки, поверхности карточек и списки выбора. Нет искусственной пустой высоты у обычных карточек; фиксированная высота нужна только функциональным областям (диалог/скролл).

## Совместимость

Производственная политика версии2 трактует products как официальный каталог. Сохранённые расчёты/незавершённые прогоны версии1 используют прежнюю проверку флага и связей; новый запуск/пересчёт — версию2. Старые поля manufactured_before/evidence продукта и product_id экспериментальной строки принимаются как устаревшие необязательные поля ради старых клиентов, истории и точного повтора ранее отправленной команды. Новая форма их не создаёт и новые правила их не используют. История и активный профиль не переписываются автоматически.

## Дизайн

Сохраняется существующая светлая зелёная палитра. Общая шкала: 4/8/12/16/24px, высота основных контролов 40px, панели с единым радиусом/внутренним отступом, списковые строки с единым фоном/выделением. Стили общих элементов принадлежат shared_ui; CompanySettings CSS использует общие токены без редактирования index.css. Новые библиотеки и новый визуальный бренд не нужны.
