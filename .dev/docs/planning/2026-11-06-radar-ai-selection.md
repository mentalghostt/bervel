# ИИ-отбор тендеров и проверка позиций

**Цель** — искать по массиву фраз, составленному ИИ из профиля предприятия, выбирать подробные карточки по оценке ИИ и проверять позиции по принципу Radar 1.

**Устройство** — новый именованный прогон фиксирует версию `ai-selection-v1`. Модель получает версию профиля и формирует массив фраз. Клиент передаёт массив в `Text` и листает общую выдачу в пределах поисковой квоты. Модель оценивает уникальные краткие карточки по заголовкам и фрагментам, а обработчик запрашивает детали по порядку в пределах лимита. После детализации запускается сопоставление позиций, остатки и дефицит рассчитывает существующий калькулятор.

Корень проекта — `C:/OSPanel/home/bervel.local`, ветка `core`, сравнение сопоставления с `12ebcdb0` (`radar-1`). Подходы `writing-plans` и `subagent-driven-development`. Работа в существующей папке с распределённым владением файлами, Git только на чтение.
