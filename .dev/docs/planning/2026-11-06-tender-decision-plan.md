# Тендер: цены, оценка и аналитическое ревью

> Исполнение: параллельные субагенты по прямому запросу пользователя; оркестрация и интеграция основным агентом. Режим АВТОНОМНО.

Цель: показать цены и понятную оценку, устранить ложную неподтверждённость совпадений, дать человеку небольшой аналитический отчёт и полезный диалог по всем доступным материалам тендера.

Архитектура: существующий Python-модуль ai_tender_radar, фоновые задания и ModelClient, React. Числа считаются предметным кодом; модель исследует данные и объясняет. Сохранённые оригиналы и прошлые расчёты в БД не переписываются: актуальная проекция карточки строится из того же исторического склада и профиля. Новые зависимости не нужны.

## Риски для независимой проверки

1. Полностью неизвестный альтернативный SKU не доказывает дополнительный остаток.
2. Несколько позиций не должны дважды тратить один SKU.
3. Цена за кг и цена за штуку не сравниваются без подтверждённого перевода.
4. Большой документ и большой профиль остаются доступны агенту порциями.
5. Старые карточки пересчитываются на сохранённом профиле; актуализация источника только в явном вопросе и без перезаписи истории.
