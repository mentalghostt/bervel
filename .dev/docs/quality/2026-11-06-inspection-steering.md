# Досылка уточнений в «Проверке»

6 ноября 2026. Исходники и тесты подготовлены. По решению пользователя установка и проверка с настроенным провайдером отложены. Рабочая БД осталась на `0027_radar_legacy_history`.

## Поведение

- Во время работы Codex в «Проверке» можно отправлять текстовые и голосовые уточнения. Enter отправляет, Shift+Enter вставляет перенос строки. Enter во время ввода через IME подтверждает композицию.
- Каждое уточнение сохраняется отдельно в истории. Worker передаёт его активному ходу через `turn/steer`; пользователь видит статус доставки и один ответ на общий ход.
- При явном отказе CLI после завершения хода уточнение становится следующим сообщением в этом диалоге. При неизвестном исходе повторная доставка исключена. Остановка блокирует ещё не переданные уточнения.
- Контракт и поведение «Ассистента» сохранены.

## Проверка

- Node на Windows — 128 из 128 тестов. Установленный Codex CLI 0.163.0 принял уточнение в активный ход и показал его в контексте после возобновления того же диалога. [Лог](../../local/inspection-steering-2026-11-06/node-suite-release.log)
- Codex CLI 0.163.0 на Linux в собранном образе с изолированным локальным провайдером. CLI запустил команду `sleep; printf` и подтвердил досылку во время её выполнения. Команда завершилась с кодом 0, итог содержал метку уточнения, зарегистрирован один завершённый ход. Отдельный прогон подтвердил возобновление нативного диалога. [Команда и уточнение](../../local/inspection-steering-2026-11-06/release/codex-linux-tool.log), [возобновление](../../local/inspection-steering-2026-11-06/release/codex-linux-protocol.log)

Девять ошибок возникли из-за отсутствия кэша токенизатора в тестовой сети. Повтор всего `test_embedding_client.py` с кэшем дал 10 из 10. ## Пакет отложенной установки

Собраны образы поверх установленных `api`, `worker-inspection`, `codex` и `frontend`. Python и Node импортируются из собранных образов, Nginx отдаёт новые JS-файлы. Сопоставление 108 файлов сборки до изменений с установленным UI показало одну разницу в сгенерированном CSS. Пакет сохраняет точную версию установленного CSS. [Сравнение файлов](../../local/inspection-steering-2026-11-06/frontend-live-baseline-comparison.json)

Предварительная проверка деклараций Compose прошла без замены контейнеров. Исходный override Codex отсутствует по пути из меток контейнера, поэтому для будущей установки подготовлена локальная декларация из параметров запущенного контейнера. Её значения окружения сверены с контейнером. Проверка обнаружила один активный прогон Радара, очередь чатов и нативных заданий была пуста.

Перед отложенной установкой заново сверить образы и параметры действующего стека. Затем выполнить проверку `install-release.ps1 -Check`. После подтверждения установки и завершения активных задач штатный скрипт сохранит резервные копии, применит добавочную миграцию 0028, обновит четыре службы и сверит настройки контейнеров и отпечатки существующей истории. После установки провести короткую досылку в отдельном диалоге на настроенном провайдере. [Локальный сценарий](../../local/inspection-steering-2026-11-06/install-release.ps1)
