## Ограничения интерпретации

Синтетический корпус проверяет конкретные контракты и края, но не полноту коммерческой поисковой выдачи. Скрытый эталон читается только после фиксации порядка; LLM его не получает. Качество ранжирования не доказывает полноту извлечения документов. Тесты не вызывали боевой Контур API.

Весовые коэффициенты — стартовая политика, требующая подтверждённых заводских данных и калибровки на ручном эталоне. Это не эмпирически доказанный оптимум. Планировщик не доказывает глобальный оптимум всех маршрутов/распределений; спорная альтернатива даёт unknown/needs_review. Сравнение тендеров не резервирует общую мощность между разными заказами.

Исторические записи без первичных материалов проверяются частично. Дата без подтверждённого часового пояса остаётся неизвестной. Большие/непрочитанные документы не усекаются молча: полнота блокируется.
