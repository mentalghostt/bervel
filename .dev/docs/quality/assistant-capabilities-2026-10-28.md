## Причины и изменения

- PDF остановился после успешного чтения11строк склада: следующий model request отклонёнHTTP429, SDK task_complete.error подтвердил причину. Теперь429 отдельно классифицируется и допускает ограниченное ожидание только явно отклонённого запроса; эффекты не повторяются.
- Native web требовал supports_standalone_web_search и маршрута /alpha/search; прежний proxy подменял tools/tool_choice и не пропускал этот маршрут. Реальные native запросы теперь проходят, xAI fallback удалён.
- Добавлены самостоятельный knowledge.search, постраничное file.read_page и точные CSV/XLSX расчёты file.query. Полнота и mock сохраняются. UI показывает человеческие названия операций/итоги и резервирует xAI для голоса.
