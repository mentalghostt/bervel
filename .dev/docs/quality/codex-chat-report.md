## Ограничения

Работоспособность настоящей генерации MOX блокируется TLS. Полный живой сценарий двух CSV и ответа модели не выполнялся после ошибки, согласно запрету владельца. Выбор последнего оригинала/редакции/области, изменение источника, сохранение истории, целостность и ограничение контекста подтверждены серверными тестами; внешний модельный ответ — только явно обозначенной фикстурой.

Текущий стенд использует общий server web key для посетителей; настройки общие для установки. Личного входа/приватности между посетителями нет. RAG ищет по последнему CSV, не по всему архиву. Не добавлены OCR/эмбеддинги/векторная БД. Перенос на сервер заказчика и промышленная нагрузка отдельно не проверялись.
