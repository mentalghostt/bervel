## Как устроено

- `frontend/src/DeleteFile.tsx`: отдельная кнопка выбранного файла и нативный modal dialog с именем, последствиями, отменой, состоянием запроса и ошибкой. Подтверждение относится к точной показанной редакции.
- `DELETE /api/v0.1/artifacts/{id}?expected_revision=N`: право `artifact:write`, собственная область данных, контроль редакции. HTTP204 после завершения очистки; повтор безопасен. Неизвестный/чужой ID —404; источник удалённого файла в своей области —410.
- `core/services.py` координирует сценарий без SQL. `infrastructure/repository.py` удаляет только строки точного artifact_id из knowledge_chunks/jobs, document_indexes/csv_chunks, artifact_revisions и связанных прежних dataset revisions/records. В общих datasets чужие редакции сохраняются, current_revision корректируется, если удалена текущая редакция. Исторические process runs/snapshots, квитанции, аудит, чаты и отчёты не очищаются.
- В artifacts остаётся минимальная отметка идентификатора/области/удаления без имени и содержимого. Прежнее логическое архивирование, при котором редакции сохранены, не получает семантику полного удаления.
- Загрузка и физическая очистка сериализованы PostgreSQL advisory lock во всех API-процессах. Объект sha256 удаляется с диска только при отсутствии ссылок на него среди всех остальных редакций и областей. Путь ограничен корнем объекта, произвольные пути не принимаются.
- Коммит БД предшествует unlink. Очередь artifact_object_deletions переживает отказ/перезапуск; knowledge-worker завершает только уже подтверждённые удаления. Ошибка одного объекта не блокирует другие удаления или индексацию. Успех не подменяет незавершённую физическую очистку.
- Активная порция индексации защищена прежним revision advisory lock:409 без изменения данных, пользователь может повторить после завершения порции. Новый worker/зависимости/внешние сервисы не добавлены.
- Миграция0010 добавляет очередь и снимает FK radar_batches к удаляемым редакциям: импорт радара является самостоятельным историческим снимком, его поля/данные/отчёты не меняются.
