## Результат

Каждый вопрос фиксирует каталог актуальных редакций **всех файлов своей области**, а не только последний CSV. Имя/тип/ID доступны независимо от наличия декодера. CSV и UTF-8 тексты индексируются; PDF читает Poppler, изображения и сканы — Tesseract rus+eng; выбранные PNG/JPEG/WebP дополнительно видит настоящий Codex через SDK local_image. Индексы, очередь и переписка хранятся в PostgreSQL. Источники содержат точные имя/ID/редакцию, строки/страницы/изображение, отрывок, статус неполноты и скачивание проверенного оригинала.

Добавлена additive миграция `0006_document_indexes`. Прежние таблицы и volumes сохранены. Runtime не зависит от `.dev`, оригиналы/SQL/проект не смонтированы в Codex. Для новых форматов достаточно расширять DocumentReader; каталог и диалог менять не требуется.

## Границы

Находить любой формат по каталогу не означает понимать любой бинарный формат. DOCX/XLSX/CAD/ZIP и другие форматы без адаптера пока доступны по имени/метаданным; они не объявляются прочитанными. Повреждённый/защищённый файл также даёт явный статус, без выдуманного содержания. OCR не гарантирует точность и требует проверки оригинала для критичных чисел.

Сейчас поиск по словам/именам, без embeddings и векторной БД. До 12 фрагментов / 16000 символов на вопрос. PDF: до 100 страниц текста, OCR до 10 пустых страниц, около 60 секунд на документ; текстовые извлечения ограничены 200000 символами. Для визуального просмотра до двух PNG/JPEG/WebP / 5 МиБ суммарно. UI принимает непустой файл до 5 МиБ. Неполнота показывается в источниках; полные итоги по большому документу без достаточного контекста не подтверждаются.

Все посетители текущего сайта используют прежнюю общую серверную область; отдельные пользовательские аккаунты и промышленное распределение прав не добавлялись. Проверка API-профиля с настоящим OpenAI-ключом не выполнялась: у владельца ключа нет, действующий доступ — MOX.
