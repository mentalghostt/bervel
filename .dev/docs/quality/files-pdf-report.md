## Реализация

PDF — отдельный инфраструктурный renderer ReportLab4.4.9, авторизованный GET завершённого запуска, прежний JSON результата остаётся неизменным. Один шаблон1.0 с A4, палитрой приложения и встроенными Noto Sans Regular/Bold. Шрифты с SIL OFL получены из официального notofonts/noto-fonts, commit `c971829a87e7920f960e7277c3dafd9bedd3c601`; файлы/лицензия включены в wheel. Нет генерируемого моделью HTML/CSS, текст экранирован, цены не переводятся в float.

Preview API читает оригинал через ArtifactService с прежними scope/permission/revision/hash проверками. CSV имеет собственные колонки, строки и пагинацию, OOXML — прежний bounded текстовый reader. Бинарные типы проверены по сигнатурам. HTML/формулы не исполняются. В браузере original Blob получается авторизованным fetch; blob URL освобождается при смене выбора. PDF.js6.4.299 загружается только для PDF, все worker/assets локальны, без внешней передачи документа. Canvas ограничен по пикселям, render/загрузка отменяются при смене файла. Boundary изолирует отказ загрузки JS-модуля; скачивание оригинала и список сохраняются.

Визуальный QA выявил пустой native iframe PDF; он заменён canvas-просмотром. В Docker Nginx базовая таблица MIME отдавала worker `.mjs` как `application/octet-stream`, что блокировало module worker. Добавлен узкий static location `application/javascript`; подмена сертификатов, VPN или внешнего шлюза не применялась. Длинные provenance CSV больше не растягивают строки: полное значение прокручивается внутри ячейки. Full-page screenshot меняет viewport и может инициировать новый canvas render, поэтому финальное изображение PDF проверено в стабильном viewport после окончания отрисовки.
