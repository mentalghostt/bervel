## Что изменено

Общий существующий путь `VoiceInput → voice API → VoiceClient → runner` обслуживает «Универсальный ассистент» и «Проверку». Runner отправляет multipart в `https://api.groq.com/openai/v1/audio/transcriptions`, `model=whisper-large-v3-turbo`, `language=ru`. Дополнительных SDK и сервисов нет. Контракт сверён с [официальной документацией Groq](https://console.groq.com/docs/speech-to-text); Context7 в этой среде ответил, что инструмент недоступен.

В настройках вместо прежней формы — «Groq: голосовой ввод» и «API-ключ Groq». Ключ остаётся серверным, не возвращается API, поле очищается после сохранения. Сохранённая запись помечается `provider=groq`; старые записи без этой метки не используются для обращения к новому провайдеру. При сохранении нового ключа прежняя запись заменяется атомарно. В действующем codex_state на момент исследования голосового ключа нет; связанных Groq-переменных окружения также нет.

Активный код и production bundle не содержат подключения, модели, формы или сообщений прежнего провайдера. Упоминание удалено из инструкции планировщику. Обновлены текущие архитектурные и операционные документы; исторические планы и отчёты сохраняют фактическую историю.

Распознанный текст добавляется в редактируемый черновик, сообщение не отправляется автоматически. Отмена и освобождение микрофона сохранены. Ограничения существующей записи 60 секунд/5 МиБ не менялись; это отдельный голосовой контракт, а не лимит файловых оригиналов.

Установлены совместимые runner/API/worker/reader/frontend из текущих runtime bases с заменой только трёх Python-файлов, `voice.mjs` и frontend. Перед заменой создана свежая копия; PostgreSQL dump восстановлен в собственную временную БД, все файлы архивов оригиналов и codex_state проверены по SHA256. Локальные image aliases указывают на проверенный выпуск.

Первое контрольное сравнение обнаружило смену Docker socket source с `/run/host-services/docker.proxy.sock` на `/var/run/docker.sock` в codex/reader. Оба подключались к тому же daemon, но для точного сохранения окружения исходный bind восстановлен через scoped Compose override с прежним read-only/read-write режимом. Повторное полное сравнение прошло; ID остальных сервисов при этой корректировке не менялись. Доказательства: `socket-binding-restored.json`, `mount-differences.json`.

Общий модельный шлюз MOX остаётся настроенным. Оба списка чатов читаются, frontend HTTP200, прежний CSP сохранён. Браузер установленного сайта подтвердил форму Groq и кнопки микрофона/поля сообщения обоих чатов; реальный микрофон не запускался.
