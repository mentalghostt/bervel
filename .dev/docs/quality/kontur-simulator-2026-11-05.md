# Симулятор Контура и подключение Радара ИИ

Проверка и установка выполнены 5 ноября 2026 года в `C:/OSPanel/home/bervel.local`, основная ветка `core`.

## Результат

Радар ИИ использует `http://kontur-simulator:8765`. Настройка сохранена в `.env` и в фактически установленных API и worker. Работают отдельные образы `bervel-kontur-simulator:api-20261105` и `bervel-kontur-simulator:worker-ai-tender-radar-20261105`. В образах обновлены семь файлов подключения, хранения признака симуляции и обработки результата. Расчёт экономики в установленных образах взят из их прежней версии, поскольку в рабочей папке обнаружены дополнительные незавершённые изменения этой части.

Симулятор содержит 120 000 записей. Доля крепежа составляет 5%, остальные записи относятся к посторонним закупкам. Обслуживание оборудования упоминает болты только в документах. Добавлены стадии, цены и валюты, неполный состав, скрытые значения и несколько лотов. Сохранены независимые квоты по 200 обращений к поиску и полным карточкам, страницы по 50 записей, предел глубины 200 страниц одного запроса и общая скорость 5 запросов в секунду.

Клиент использует отдельный тестовый ключ для локального источника. Переадресация запрещена, HTTP-прокси для симулятора отключён. Неподходящая пара адреса и ключа отклоняется до сетевого обращения. При недоступном симуляторе возникает ошибка соединения. Признак симуляции сохраняется в снимке и карточке, результат получает `mock=true`. Повторный анализ проверяет источник исходной карточки.

## Проверки

Основной целевой прогон завершён с результатом **91 passed**. Он включает симулятор, клиент, HTTP-сценарий, задания, анализ, конфигурацию и распределение обязанностей worker. Проверки с PostgreSQL использовали отдельную тестовую БД `bervel_core_stage31_test` и временные схемы. Для неё включён доступный pgvector. Audit hook Python запрещал соединения вне loopback, включая боевой API Контура.

После основного прогона отдельно прошли пять проверок адреса, ключа и недоступного симулятора, а также одна проверка совместного применения региона, закона, отрасли, заказчика и срока подачи. Четыре из этих пяти проверок уже входили в основной прогон. Всего проверено 93 уникальных целевых теста. Единственное предупреждение основного прогона относится к устаревающему использованию httpx в Starlette TestClient.

Общий набор проекта проверен частично. Прогон был остановлен после 250 успешных тестов. Итоговая проверка изменений выполнена отдельным целевым прогоном с изолированными временными каталогами.

## Граница совместимости

Совместимость проверена на методах и полях, которые использует Радар ИИ, и сохранённой OpenAPI-схеме. Полный коммерческий сервис Контур.Закупок имеет закрытый индекс, морфологию, ранжирование и другие методы. Поиск симулятора использует ограниченный словарь словоформ, поддерживает только перечисленные в инструкции фильтры и отклоняет остальные с HTTP 400. Сброс квот происходит при перезапуске процесса. Поэтому совпадение поисковой выдачи с реальным Контуром и полная эквивалентность всех методов не подтверждены.

Контракт и правила эксплуатации описаны в [инструкции симулятора](../operations/kontur-simulator.md). Основные воспроизводимые доказательства находятся в [результате живой проверки](../../local/kontur-simulator-2026-11-05/live-proof.json) и [контроле установки](../../local/kontur-simulator-2026-11-05/installation-proof.json).
