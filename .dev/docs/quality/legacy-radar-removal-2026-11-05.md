# Удаление обычного тендерного радара — этап 1

Второй этап также выполнен 5 ноября: приложение обновлено, старые API/таблицы/контейнер удалены из работающей версии. Актуальный итог — [отчёт установки](legacy-radar-removal-deployment-2026-11-05.md). Ограничения ниже описывают промежуточное состояние первого этапа.

Рабочий корень: `C:/OSPanel/home/bervel.local`, основная ветка `core`. Пользователь согласовал удаление обычного радара, всех его подключений и истории; ИИ-радар и его данные сохраняются. Полное обновление установленного приложения — отдельный этап.

## Исходники и подключения

- Удалены 29 Python-файлов `src/bervel/modules/tender_radar/`, 10 файлов старого UI и его вспомогательных функций, отдельные устаревшие тесты и три сценария старого радара. Исторические миграции сохранены.
- В `app_setup.py` больше нет `RadarService`, старого router и зависимости ассистента от него. Удалены операции `radar.*`, их планирование, обработка результатов и карточки в чате.
- В `App.tsx` удалён маршрут `#/radar`; такой старый адрес попадает в общий список файлов. ИИ-маршрут `#/ai-tender-radar` сохранён.
- Удалены роли `radar` из CLI/worker и сервисы `worker-radar`/`worker-radar-e2e` из Compose. Очищены dev-конфигурация, запуск workers и тестовые команды. Старые API исключены из разрешённых чтений «Проверки».
- Общая проверка складского CSV перенесена из удалённого `radarSources.ts` в `frontend/src/api.ts` без изменения поведения. Общие стили заголовков и поиска ИИ-радара сохранены.
- Миграция `0024_retire_legacy_radar` удаляет две старые таблицы и только записи с `operation LIKE 'radar.%'` в общей истории. Из `chat_turns.results` она удаляет только старые карточки/результаты, сохраняя остальные элементы и сообщения.

## Очистка рабочей БД

В рамках этапа остановлен только `bervel-worker-radar-1`. Скрипт `.dev/local/retire-legacy-radar-2026-11-05/purge_live_history.py` выполнил очистку одной транзакцией с проверкой имени БД и отсутствия активных старых заданий. При изменении любых защищённых данных транзакция была бы отменена.

| Объект | Удалено |
|---|---:|
| `radar_runs` | 37 |
| `radar_batches` | 28 |
| `command_receipts`, только `radar.*` | 65 |
| `audit`, только `radar.*` | 65 |
| `chat_actions`, только `radar.*` | 0 |

Все 23 защищённые таблицы совпали до и после очистки. У всех 356 строк `ai_tender_radar_jobs` и 126 общих файлов совпали полные контрольные суммы строк. Все 15 защищённых файлов исходников ИИ-радара совпали по SHA256. Доказательства — `live-purge.json`, `ai-data-baseline.txt`, `ai-data-after.txt`, `ai-source-baseline.json` в каталоге этапа.

Пустые старые таблицы оставлены до обновления установленного приложения. Рабочая БД остаётся на миграции `0023`; `0024` применена только в изолированных тестовых схемах. Установленные API/frontend пока предыдущей версии: они всё ещё содержат старые маршруты и могут снова принять старую команду. Полное прекращение таких обращений требует второго этапа. Новые образы и полный деплой на этапе 1 не выполнялись.

## Проверки

- До изменения реализации: 10 новых проверок воспроизвели прежние подключения и наличие старых таблиц. После удаления все 10 прошли.
- Миграция проверена настоящим переходом с заполненной `0023` на актуальную схему: удаление legacy-таблиц/квитанций, сохранение полных AI-снимков, файлов и прочих карточек чата.
- `npm run build` прошла; Vite предупредил о крупных уже существующих пакетах Mermaid/PDF. `npm run lint` завершилась с кодом 0 и предупреждениями в прежних `PdfPreview.tsx`/`TestChat.tsx`, которые не менялись.
- 117 Node-тестов и 6 проверок отображения экономики/позиций ИИ-радара прошли.
- Новый браузерный тест `frontend-legacy-radar-removal.cjs` прошёл на 1440 и 390 px: старый адрес не запускает радар/API, навигация ИИ-радара, форма, перезагрузка и отсутствие горизонтального переполнения работают.
- Полный Python-прогон: 694 прошли, 7 устаревших ожиданий упали. Фикстуры обновлены под удаление: историческая миграция проверяется на `0013`, действующие снимки — на AI-таблице. **Повторный прогон всех затронутых серверных сценариев: 200 passed**, включая все семь прежних падений, новые проверки удаления, API/worker/ассистент, изоляцию файлов, чаты и «Проверку». Логи — `python-full.log` и `python-affected.log`. Повторно полный набор из 701 проверки не запускался.
- Прежний `frontend-ai-tender-radar.cjs` воспроизвёл несоответствие существующему интерфейсу: ищет ссылку «Тендерный радар ИИ», хотя уже до этой задачи она называлась «Радар ИИ», и ожидает прежнюю форму. Прогон прерван; функциональность ИИ-радара ради этого старого сценария не изменялась. Актуальная браузерная проверка этапа проходит. Использован установленный Chrome, без установки браузеров.

## Ограничения

Автоматическая проверка отклонила удаление оставшихся `.pyc` старого пакета с причиной `blocked by policy`. Исходники удалены через `apply_patch`; кэш/каталоги остались. Запрет не обходился. VPN, Open Server Panel, другие контейнеры, исходники ИИ-радара и его рабочие данные не изменялись. Git использовался только для чтения; общий dirty tree других задач сохранён.
