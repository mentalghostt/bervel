## Проверка поиска и ранжирования

Штатная модель сформировала 284 уникальные фразы из снимка профиля. В выборке из шести сохранённых кратких карточек закупка болтокомплектов получила 66 баллов, крепёж для котельной — 58, услуги техзаказчика — 3, незамерзающая жидкость — 2. Для каждой оценки модель вернула цитату, которую проверил код. Сводка записана в `ai-selection-model-smoke.json`. На всех 890 кратких карточках полнота передачи модели проверена тестовым двойником. В этой проверке использовано 29 пакетов и каждый кандидат оценён один раз.

На симуляторе проверены точный массив `Text` в двух запросах, переход между страницами, повторное использование фраз при продолжении и дедупликация. Интеграционные тесты проверяют выбор ID по рейтингу ИИ, учёт закрытия закупки между рейтингом и детализацией и оценку только новых кандидатов после пополнения поисковой квоты. Ошибка ранжирования завершает прогон до запроса деталей. Целиком готовый рейтинг сохраняется в прогоне. При остановке внутри первого ранжирования ручное продолжение заново оценивает незакреплённый набор.

Новая версия подключена для новых именованных прогонов с источниками «Тестовый API» и «Контур.АПИ» в исходном коде. Работающие образы не заменялись. Проверки не обращались к Контуру, поэтому логика объединения массива у провайдера и качество выдачи после перехода на общий запрос остаются непроверенными.
