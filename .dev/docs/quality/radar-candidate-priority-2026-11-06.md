# Отбор тендеров при ограниченной квоте

Для сравнения взяты шесть независимых наборов локального симулятора по 1000 карточек. В каждом 30 закупок с полным соответствием каталогу. Старый и новый порядок получили один пул кратких карточек и одинаковые поисковые бюджеты. Колонки показывают суммы по шести запускам для каждого лимита подробных карточек.

| Раскрытий за прогон | Подходящие лоты, старый → новый | Тендеры с подходящими лотами | Тендеры со всеми подходящими лотами |
| ---: | ---: | ---: | ---: |
| 10 | 140 → 157 | 37 → 39 | 4 → 8 |
| 50 | 489 → 657 | 165 → 194 | 20 → 26 |
| 200 | 2307 → 2633 | 749 → 793 | 64 → 94 |

Источник метрики — проверка позиций каждого раскрытого лота по каталогу, без учета складского остатка. Подробные карточки доступны только оценщику. Код очереди получает профиль предприятия, заголовок и фрагменты поисковой выдачи. Идентификатор используется при равенстве. Результаты описывают эти наборы, а не частоту попаданий в боевом Контуре.

Для первых десяти запросов очередь учитывает число упоминаний, совпадение технических признаков и предмет закупки. Дальше наибольший вес имеет число упоминаний. Сравнили также простой подсчёт, добавление старой оценки, уточнение порядка после каждой партии из четырёх раскрытий и расширенный поиск по товару и стандарту. Дополнительный поиск и изменение очереди по ходу прогона не дали устойчивого прироста. В контрольной выборке с модельным переранжированием правила нашли 24 подходящих лота, модель — 19. По одному полностью соответствующему тендеру в обоих вариантах.

Старый разбор отклонял требования `Длина` и `Диаметр резьбы`, привязанные в спецификации к одной строке, после сравнения со всеми позициями. Теперь объём, единица и название связывают строку с позицией, включая числовую запись вида `1.0E+1`. Подтверждённые дубли исключаются из входа модели. Противоречивые или непрочитанные требования оставляют карточку неполной. Суммарный вход для десяти сохранённых карточек уменьшился с 259 987 до 104 215 байт. Проверка извлечения с контрольным ответом прошла на всех десяти. Три отдельно проверенные карточки с 13, 20 и 38 позициями обработаны моделью за 25,70, 10,58 и 9,51 секунды соответственно.

Воспроизведение сравнения в окружении с `PYTHONPATH=src:.dev/scripts`:

```sh
python .dev/scripts/benchmark_radar_priority.py .dev/local/radar-unified-2026-11-05/deployment/sim-stock.private.csv --negatives 970 --seeds 82153 91639 100003 82759 99397 105019 --broad-only
```
