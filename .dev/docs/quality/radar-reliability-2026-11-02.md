## Поведение

- Складской CSV читается целиком бизнес-импортёрами, без ожидания общего RAG. Текущий файл: 3076 строк, 177 колонок, 3078798 байт, SHA256 `c71b1e10f28a96ba3f6f62f3632d5ffa0f0ae92fa86e21fdaee4e2a228af7c58`. Файл не изменён, цены продажи в него не добавлялись.
- Локальный E5 ищет кандидатов по всем SKU, модель получает полные раскрытые требования и непустые свойства кандидатов. Глобальный поиск чата/проверки не переключался. Компактный индекс: 101 языковой профиль, первоначальный benchmark около 7 секунд.
- Поле ключевых слов удалено. Сервер выводит неповторяющиеся формы ед./мн. числа из склада. Основы слов не используются: 12 реальных SEARCH показали потерю результатов. Дополнительные пробы общей группы крепежа и одного flat-запроса не дали оснований заменить групповой план.
- При выборе карточек из уже просмотренного пула явные товарные названия имеют приоритет. Исходные ответы не сортируются и не переписываются; бюджет GET общий, ID дедуплицируются, слабые названия не исключаются. Решение о соответствии принимается только по Objects, либо по вложенному описанию, когда Objects отсутствуют.
- Неуказанные параметры свободны: «болт М12» допускает разные длины/прочности/покрытия. Все предъявленные требования проверяются; options не заменяют факты. Для положительного соответствия нужен хотя бы один конкретизирующий признак, а не только общая товарная группа. ГОСТ не обязателен.
- Основной список показывает подтверждённое положительное покрытие строк, в том числе при неизвестном общем проценте. Сортировки и диапазоны готовности 0–100, выгоды −100…100 сохранены. Масса переводится в штуки только по подтверждённой детали; неизвестные данные не превращаются в нули.
- Успехи и блоки описания сохраняются. Один неверный ответ допускает одно исправление. Rate/busy ждут retry_at, длинный Retry-After не сокращается; исчерпанная квота терминальна. Неизвестный исход запроса и сохранённая терминальная ошибка не повторяются автоматически.
