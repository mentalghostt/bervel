# Единый Радар ИИ — проверка 5 ноября 2026

Последующее исправление оформления и остановка нового пользовательского прогона: `.dev/docs/quality/radar-design-restore-2026-11-05.md`. По уточнению владельца история может сужать список, но остальной дизайн результатов должен совпадать с прежним интерфейсом; лишняя кнопка настроек удалена. Первоначальное описание выпуска ниже остаётся историческим.

Статус: изменения установлены и проверены в работающем приложении. По последнему прямому указанию пользователя сегодняшний прогон удалён; в истории остались только 179 «Результатов до обновления».

## Поведение

- Один интерфейс `#/ai-tender-radar` на прежней сетке карточек и попапе. `#/ai-radar-runs` совместим со старыми ссылками. История, операции, прогресс, подробности позиций, ревью, вопросы и пересчёт доступны здесь.
- Вся плашка открывает попап; hover/focus плавно меняет фон и название. Enter/Space, Escape, возврат фокуса, вложенные действия и reduced-motion проверены.
- Новая форма: название и источник (тестовый API / Контур.АПИ / JSON-файл). Нет склада, фразы, количества страниц или тендеров.
- Старые карточки объединяются первой архивной записью со ссылками на исходные задания. Их расчёты не переписываются; отсутствующий исторический балл не выдумывается. Старые прогоны сохраняются.
- В новых прогонах нет суммарных ограничений 200 карточек/страниц и 1000 вызовов модели. Сохраняются реальные квоты провайдера, предел страницы и конечный снимок области поиска. Попытки и исходные данные записываются до внешнего действия; явное продолжение сохраняет готовые результаты и историю попыток.
- Дешёвый предфильтр не заменяет окончательный анализатор. Основная подборка требует подтверждённого фактического покрытия от 80%; 100% идут первыми. Низкое и неизвестное покрытие доступны отдельно.
- `matching.py` и `calculation.py` совпадают с замороженными SHA256. Производственная возможность не прибавляется к фактическому складскому покрытию.

## Независимый эксперимент

Авторы нового предфильтра и симулятора работали раздельно и не получали данные/эталон друг друга. Измеритель видел обе части. Первый неудачный blind сохранён без изменений; последующие версии и исправления имеют отдельные отчёты.

Для актуального склада с остатками 0–200 создан отдельный корпус: три seed по 1350 закупок, в каждом 150 положительных и 1200 похожих отрицательных. Старые данные/истина не переписаны. Истина не выдаётся через тестовый API и не передаётся модели.

Предфильтр v3 на семи наборах сохранил 1230/1230 положительных по эталону; безопасно отклонил 6750 из 10230, ещё 2250 оставил неопределёнными. Это проверка предфильтра, а не гарантия окончательного совпадения модели.

Полный проход актуальных 1350 с моделью-заглушкой:

| Результат | Количество |
|---|---:|
| Основная подборка, actual 100% | 100 |
| Требуют данных | 350 |
| Отклонены | 900 |
| Технически failed | 0 |

Все 100 принятых были положительными по эталону. Все контрольные мыло, чужие компании, 2/6%, неверные размеры и стандарты отклонены. 50 эталонных 80/90% остались `needs_data`, а не были объявлены подтверждёнными. Выполнены 1350 загрузок, 35 поисковых запросов, 1000 вызовов заглушки; полный обход подтверждён. Время 309,72 с включает 159,01 с сериализации снимков тестового репозитория; это не замер рабочего HTTP/PostgreSQL и не время реальной модели.

Операционный синтетический контроль 520 закупок/один SKU подтвердил обработку 520 карточек и 1040 модельных вызовов без прежних caps. Повторное продолжение не вызвало дополнительных загрузок или модельных запросов. Отдельно проверены 429, исчерпание/обновление квот и сохранение уже готовых карточек.

## Реальная модель и ограничения

Первый контроль десяти кандидатов дал 0 готовых результатов. Повтор после устранения конфликта четырёх потоков с лимитом runner 2 и ошибки табличного срока доставки занял 112,70 с / 14 реальных вызовов: 0 `MODEL_BUSY`, но 0 готовых / 7 требуют данных / 3 отклонены. Это не «10 готовых за две минуты».

Диагностика выявила несогласованность nullable JSON-схемы обязательных фактов и проверки единиц документов. Исправления проверены отдельно; строгая проверка настоящих противоречий сохраняется.

Первый отдельный положительный функциональный контроль после этих исправлений: 1 actual 100% с полным ревью и 1 отклонённый из двух за 43,66 с. Это выбранный положительный контроль, не слепая оценка полноты. Второй эталонный full100 не принят после добавления документальных требований «точность»/«шаг», не доказанных неизменным анализатором. Утверждать «найдены все 150» нельзя. Финальный контроль того же ранее принятого тендера на окончательном строгом guard: 1 accepted, actual100%, ревью complete, 47,26 с, три реальных вызова, ошибок нет. Подробности — `benchmark/final-addendum.md`; прежние неудачи не переписаны.

Большой старый baseline остановлен как `INCOMPLETE` после примерно 2262 с; успешным не считается. Порог 120 с не является критерием приёмки по последнему уточнению владельца.

## Установка

Установлены `bervel-radar-unified:{api,worker-ai-tender-radar,frontend,kontur-simulator}-20261105`; обычные локальные теги API/frontend обновлены с сохранением прежних ссылок. Миграция 0027 добавила только архивную группу. Сверка при установке подтвердила неизменность всех прежних строк, точное членство 179 карточек архива, окружение, команды, порты, хранилища и остальные container ID.

При проверке реального запуска устранены две ошибки упаковки/HTTP симулятора: добавлен совместимый импортируемый service.py и сохранён допустимый Host/порт в ссылках документов. Защита клиента не ослаблена. Три small-stock wire/truth регенерированы и совпали по SHA; оба прежних frozen manifest и все старые wire/truth неизменны. Реальный HTTP smoke через установленный API загрузил 50 brief, полную карточку и документ, без модели; сервер работает без рестартов. Обновлён рецепт `.dev/docker/compose.kontur-simulator.yaml`.

Установленные восемь экранов на 1440/390 проверены без mocks: ошибок страницы, API и попыток записи 0. Попап открывается всей плашкой; hover, клавиатура, форма и 179 архивных карточек подтверждены. Отдельная подготовленная проверка Company UI также PASS: профиль, 3076 товаров/производственных записей, три линии, эксперимент и сроки доверия не изменились.
