Начальная страница — «Файлы» с существующей загрузкой произвольного оригинала. Worker обслуживает чат и радар.

Чтение документов, CSV-декодер, DocumentReader/Memory, индекс версии 4, preview, модули чата/радара, импорт закупок и PDF сохранены. 36 защищённых файлов побайтно совпадают с началом задачи. Формат canonical_json для старых command receipts подтверждён сравнением AST до/после переноса функции.

Из runtime исключены 16 неиспользуемых зависимостей: пакетов стало 28 вместо 44. Версии оставшихся пакетов не изменены. Реальное сокращение относится к учебному контуру; исторические SQL-описания остаются для сохранения схемы и данных.

## Доказательства

- До изменений новые регрессии дали 3 ожидаемых падения: старые endpoints были доступны, список содержал dataset, worker требовал учебный сервис.
- Backend из установленного wheel: **168 passed**. Пройдены рабочие проверки чтения документов, CSV preview/индекса, scope/прав, чата, выбранных редакций, радара, импорта, ошибок модели и PDF. Имеется прежнее предупреждение библиотеки о Starlette TestClient; отказов нет.
- Браузер: **28 passed**, включая настоящую загрузку произвольного CSV, preview и reload через тестовую установку. SQL подтвердил оригинал и отсутствие нового учебного dataset.

## Применение и сохранность

Проверенные образы установлены в основные api/worker/frontend; они запущены и прошли healthchecks. Перед заменой очереди чата/радара были пусты. PostgreSQL, codex, внешние credentials, MOX/VPN и Open Server Panel не перенастраивались.

До/после применения совпали количество и контрольный хеш содержимого каждой из **19 таблиц, всего 341 запись**, а также SHA-256 **16 файлов оригиналов**. Миграции 0001–0007 не менялись; DROP/DELETE и преобразования старых записей не выполнялись. Основная установка проверена чтением: файлы, радар, новый список оригиналов и отсутствие учебных endpoints в OpenAPI. Новый вызов платной модели для приёмки не выполнялся; сохранность её рабочих путей подтверждается регрессиями, неизменностью их исходников и штатным запуском.

Существующие разрешения и legacy-метки метаданных сохранены для совместимости; они не включают удалённый учебный обработчик. Из API списка и истории исключены поля учебных результатов `dataset`/`datasets`.
