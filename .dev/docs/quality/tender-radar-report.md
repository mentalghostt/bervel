## Сохранность и ограничения

Additive migration `0007_tender_radar` добавила две таблицы. Fingerprints прежних строк 11 таблиц совпали, включая 18 artifacts/22 revisions, 9 datasets/13 revisions/26 records, 13 process_runs/13 snapshots, audit/receipts/jobs/attempts. Новые контрольные записи учтены отдельно. [preservation.json](../../local/tender-radar/preservation.json): `prior_tables_match=true`, `mox_auth_unchanged=true`, `mox_config_unchanged=true`, mismatched=[]. Проверены хеши credentials без копирования/печати содержимого. VPN/OSP/MOX не перенастраивались, volumes не удалялись, Git только чтение. Изменения остаются незакоммиченными в исходном `core` рядом с прежней работой.

Не реализованы непредоставленное API, постоянная синхронизация и скачивание полного комплекта тендера. Свежесть для допуска — до 24 часов; сохранённый отчёт историчен. До 12 кандидатов/выбранные RAG-фрагменты: полнота большого массива и промышленная точность не доказаны шестью карточками. В пакете нет утверждённых мощностей, остатков, себестоимости, сертификатов, правил замен/экономики. Для решения об участии нужны эти данные и проверка сотрудника.
