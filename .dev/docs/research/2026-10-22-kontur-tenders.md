## Вывод для интеграции

Самостоятельно получить бесплатный API-ключ без заявки по проверенным официальным материалам **не подтверждено**. Анонимный тестовый endpoint и готовый публичный JSON-пример именно API Закупок не найдены. На этой основе нельзя писать рабочий API-клиент, выдумывать заголовок авторизации или переносить протокол от других продуктов Контура.

Для текущей проверки приложения доступны: предоставленный заказчиком XLSX (исторические данные, не текущая лента) и отдельный небольшой набор реальных публичных карточек. Это ручной снимок, не непрерывная интеграция и не официальный экспорт.

## Что подтверждено об API

- Документация разработчика: [developer.kontur.ru/doc/zakupki.external_api?about=0](https://developer.kontur.ru/doc/zakupki.external_api?about=0). Web-чтение возвращает JavaScript shell. Прямой браузер действительно перенаправил на **auth.kontur.ru**, страницу «Вход в экосистему Контур». За авторизацию не переходили.
- [Договор №26/26](https://zakupki.kontur.ru/site/licence-kontur), п.4.4: ключ разработчика предоставляется после оплаты API-лицензии в течение пяти календарных дней. Это документированная схема обычного доступа; она не доказывает отсутствие индивидуального пробного предложения.
- [Официальный API-лендинг](https://zakupki.kontur.ru/lp/api) содержит «Попробовать бесплатно», но ссылка ведет к оставлению заявки. Самостоятельная выдача тестового ключа или анонимная песочница не подтверждены.
- [Дополнительный API-прайс](https://kontur.ru/Files/Modules/LandingPage/5242/price_skb_kontur.pdf), доступный файл от 01.01.2026: поиск выдает до 50 закупок за запрос и до 10000 по одному поиску; подробная информация получается по ID; ограничение до 5 запросов/сек. Названы тарифы поиска, подробной информации и результатов. Это коммерческие описания методов, а не техническая спецификация URL/параметров.

**Не установлены:** базовый URL сервера именно Закупок, HTTP-методы и пути, формат авторизации, имена JSON-полей, схема пагинации и ошибок, пример успешного ответа. Подтвержден только факт применения ключа разработчика. OAuth-протокол входа на портал документации не равен протоколу доступа к API закупок.

## Excel: штатный сценарий и ограничения

[Функция Избранного](https://zakupki.kontur.ru/site/features/lk) описывает последовательность: найти закупки → добавить в Избранное → при необходимости отфильтровать метки/этап → выгрузить Excel с выбранными колонками. [Выгрузка шаблонов](https://zakupki.kontur.ru/site/articles/53162-uluchshennaya_vygruzka_v_excel_iz_shablonov) формирует общий лист «Все шаблоны» и отдельные листы шаблонов.

[Действующий web-прайс с 15.09.2026](https://zakupki.kontur.ru/site/Files/userfiles/file/price-zakupki-skb.pdf), таблица тарифов: Excel входит в Стандарт и выше, не в Лайт. Раздел 5 разрешает трехдневное Промо уровня Эксперт после регистрации с действующим email; при экспорте в Промо скрыты контакты и ИНН в блоках заказчика/результата. Поэтому **без оплаты, но с зарегистрированным Промо Excel предусмотрен; анонимный экспорт без аккаунта не подтвержден**. Промо не подтверждает доступ к API.

Официальный загружаемый образец XLSX и фиксированная полная схема колонок не найдены. Колонки выбираются пользователем. У заказчика уже есть историческая выгрузка F02 —2.xlsx: по сообщению основного исследователя, строка 4 содержит «Номер», «ИКЗ», «Название», «НМЦ», «Валюта закупки», «Дата публикации», «Окончание приема заявок», «Тип торгов», «Ссылка на ЕИС», «Способ отбора», «ЭТП» и блоки заказчика/регионов; реальные URL находятся в hyperlinks. Это сведения о предоставленном файле, **не гарантия универсальной схемы сервиса**; сам файл этот субагент не анализировал.

## Рекомендация для приложения

Импортировать предоставленный XLSX с чтением настоящих hyperlinks; сохранять источник/дату загрузки; показывать историчность старых карточек. Для актуального теста отдельно загрузить нормализованный снимок шести публичных карточек, сохраняя различие свежих видимых полей и индексированного состава. Не рассчитывать на web-парсинг как постоянный источник: это неполная публичная витрина с ограничениями.

До появления законного доступа к технической документации и ключу не включать «живой API Контур» и не имитировать успешную синхронизацию. Для регулярной работы практический резерв — новые ручные XLSX-выгрузки пользователя; API остается отдельным подключением после подтверждения прав и фактической схемы.

Публичные страницы подтверждают данные для исследования, а не безусловные права массового сбора, перепродажи или повторного опубликования базы. Никакие закрытые endpoint, маскированные поля браузера, CAPTCHA или авторизация не обходились.
