# Оркестрация выбирается по восстановлению, а не названию «агент»

КП содержит n8n + Python. Temporal предложен как альтернативный движок долгих процессов. Переключение ещё не принято. Выбор должен подтвердить восстановление после сбоя, ожидание сотрудника, безопасные повторы и изменение версии при незавершённых заданиях.

n8n сохраняет близость к предложенному решению и интеграциям; Temporal усиливает модель долговременного исполнения ценой отдельной эксплуатации. Сначала технический эксперимент и оценка бюджета/компетенций. Два движка одновременно не вводятся автоматически.

Бизнес-правила и версии результатов остаются вне визуальной схемы конкретного оркестратора. См. [стек](../architecture/08-stack-deployment.md).
